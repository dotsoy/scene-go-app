## 0. 如何使用本文档

- **设计 agent**：按「§4 逐屏规格」在画布上重建 13 个屏幕，采用 §2 设计令牌，按 §5 链路关系排列。

## 1. 产品上下文

**SceneGo** — 面向境外出行的主动表达翻译助手。用户**主动**拍照 / 说话 / 打字，AI 识别场景并生成符合场景的当地语言表达卡，可递给司机、店员、警察。三模态输入统一收纳在**对话页输入栏**中。

| 能力 | 说明 |
|---|---|
| 统一对话流 | 拍照解读、语音转写、文字追问、表达卡生成全部发生在同一条对话时间线 |
| 三模态输入 | 输入栏 `📷 拍照` / `🎙️ 语音` / `输入框打字`，主动触发 |
| 表达卡 | 对话流中以半屏大字消息呈现，点击全屏最高亮度大字展示 + TTS + 本地提示 |
| 追问生成卡 | 多轮追问中表达沟通需求 → AI 直接输出表达卡入对话流 |
| 卡栈管理 | 底部 Tab「卡栈」：最近 N 张 + 场景分类浏览，点卡全屏 |
| 快速笔记 | 凭证/密码/退款号，语音自动归档 |
| 安全指南 | 按国家内置紧急电话/求助句/使领馆/骗局，一键拨打 |
| 工具箱 | 会话历史 / API 日志 / 识别引擎设置 / 切换国家 |

## 5. 交互链路

```
主流程：
01 对话页 ──📷──▶ 06 取景 ──单击SNAP──▶ 01 解读消息 ──▶ 01 表达卡消息 ──点击──▶ 02 全屏大字卡
   │ 🎙️语音→转录横幅→表达卡消息          │ 打字→追问/AI回复→表达卡消息      │ PLAY AUDIO / AI 解读
   ▼                                                                        ▼
03 卡栈页 ──点击任意卡──▶ 02 全屏大字卡                                    08 安全详情
04 笔记页（Tab）  05 更多页（Tab）──▶ 07 安全卡 / 11 会话历史 / 12 API日志 / 13 引擎设置
09 国家选择 ──GPS变化──▶ 10 位置提示
```

**关键流程说明**：
1. **首次启动**：09 国家选择（GPS 高亮）→ 确认 → 07 安全卡入卡栈；再启动 GPS 变化 → 10 切换提示
2. **拍照**：01 输入栏 `📷` → 06 全屏取景 → 单击 SNAP → 回 01 追加解读消息（含照片缩略）
3. **语音**：01 输入栏 `🎙️` → 转录横幅（REC）→ 停止 → 表达卡消息入流 + 语音自动归档 04 笔记
4. **打字**：输入框 → 追问（AI 文本回复）；表达沟通需求 → 表达卡消息 + 系统提示 `✅ 已生成表达卡`
5. **卡片**：任何表达卡消息 / 03 卡栈卡片 → 02 全屏大字卡（TTS / AI 解读 / 本地提示）
6. **Tab**：`💬 对话` 默认；`🎴 卡栈` 浏览管理；`📝 笔记`；`⚙️ 更多` → 安全/历史/日志/设置

## 6. 实现约束与建议

### Pencil / 设计画布
- 每屏 390 宽 844 高、`clip:true`、背景 `$bg-primary`；禁止 `margin`/百分比尺寸；Flex 单轴
- 文本必须设 `fill`；长文本 `textGrowth:"fixed-width"` + `width:"fill_container"`；不要猜文本尺寸
- 屏间标注为画布辅助元素，不参与产品 UI

### React Native 实现
- 深色主题统一令牌映射；状态栏 `barStyle="light-content"`
- **导航**：无路由库，四 Tab 用状态驱动（`activeTab`）；全屏大字卡 / 取景 / 各子页用全屏覆盖层或 `Modal`
- 新增组件：`ChatPage`（对话流渲染器，消息类型分发）、`ChatInputBar`（📷🎙️⌨️⬆️）、`TabBar`、`CardStackPage`、`MorePage`；`FlashCardView` 保留为全屏大字卡层
- 消息类型：`ChatTurn` 扩展 `kind?: 'user' | 'assistant' | 'card' | 'system'`，表达卡消息携带 `ScenarioResult`（或 CardData）直接渲染
- 输入链路复用现有：`NativeSpeech`（MIC）、`pluginManager.processImageSnapshot`（📷）、`generateCardFromText`（打字/追问）、`addExpressionCard`（表达卡入栈，卡栈与对话流共享同一数据源）
- 数据（安全电话/求助句/骗局）来自 `src/data/countrySafety.ts`，严格使用真实值
- 交互手势：SNAP 单击=拍照发送；🎙️ 单击=开始/停止听写；表达卡点击=全屏大字
