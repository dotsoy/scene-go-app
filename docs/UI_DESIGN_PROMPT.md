# SceneGo UI 设计稿 — 可执行实现 Prompt

> 本文档是 SceneGo（零搜索出境游翻译助手）完整 UI 设计稿的结构化描述，供其他 AI agent（设计/编码）直接据此重建或实现界面。配套源文件：`pencil-new.pen`（Pencil 画布）。

---

## 0. 如何使用本文档

- **设计 agent**：按「§4 逐屏规格」在画布上重建 12 个屏幕，采用 §2 设计令牌，按 §5 链路关系排列。
- **编码 agent**：按「§4 逐屏规格 + §3 组件清单」实现 React Native 界面，样式对照 §2 令牌，交互对照 §5 链路。
- 所有尺寸以 `pt` 为单位；屏幕画布为 390pt 宽手机（iPhone 级），高度按内容自适应（`fit_content`，上限约 844）。

## 1. 产品上下文

**SceneGo** — 面向境外出行的零搜索翻译助手。用户拍下眼前的菜单/标牌/售票机，AI 解读场景并生成高对比当地语言表达卡，可递给司机、店员、警察。核心能力：

| 能力 | 说明 |
|---|---|
| 场景快照分析 | 拍照 → 云端视觉模型识别 → 结构化解读（类别/标题/译文） |
| 多轮追问 | 对同一照片持续追问（价格/过敏源/路线），会话本地持久化 |
| 零搜索表达卡 | 高对比大字卡 + 音标 + TTS 朗读 + 本地指南提示 |
| 实时语音转录 | 原生 SFSpeechRecognizer，麦克风双击生成表达卡，语音自动归档笔记 |
| 快速笔记 | 凭证/密码/退款号，分类管理、一键复制、全屏大字展示 |
| 会话历史 | 本地保存快照会话，可恢复追问 |
| 安全指南 | 按国家内置紧急电话/求助句/使领馆/骗局提示，支持一键拨打 |
| 工具箱 | API 日志监控 / 对话记录 / 识别引擎设置（OCR 引擎 + API Key） |

### 2.3 通用样式约定

- 卡片：`fill #121214`，`cornerRadius 10–16`，`stroke border-subtle 1px`
- 药丸/标签：`fill $bg-card-light`，`cornerRadius 6–12`，`padding [4–6, 10–14]`，小字号 `10–12` 加粗
- 主按钮（蓝色）：`fill $accent-blue`，文字 `#0a0a1e` 加粗；危险按钮：`fill $accent-red-bg` 文字 `$accent-red`

- 屏幕：390 宽，`clip: true`，背景 `$bg-primary`；内容统一左右留白 20
- 底部控制栏：高 72，`fill $bg-bar`，按钮 `justifyContent: space_between`

## 6. 实现约束与建议

### Pencil / 设计画布
- 每屏 390 宽、`clip:true`、背景 `$bg-primary`；模态类屏幕底部遮罩 + 内容卡，主流程屏幕完整渲染
- 禁止 `margin`/百分比尺寸；间距用父级 `gap` + 子级 `padding`；Flex 布局单轴，网格用逐行 frame
- 文本必须设 `fill`；长文本用 `textGrowth:"fixed-width"` + `width:"fill_container"`；不要猜文本尺寸
- 屏间标注（标题条/箭头）为画布辅助元素，不参与产品 UI

### React Native 实现
- 深色主题统一用令牌映射；状态栏 `barStyle="light-content"`
- 卡片、药丸、按钮做成可复用组件（`FlashCard`、`ControlBarBtn`、`Sheet`、`DialRow` 等）
- 模态：`Modal transparent` + 底部抽屉（`animationType="slide"`）或居中卡（`fade`）
- 数据（安全电话/求助句/骗局）来自 `src/data/countrySafety.ts`，严格使用真实值
- 交互手势：SNAP 双击=拍照分析/单击=关闭；MIC 双击=生成卡/单击=关闭（`useDoubleTap`）

## 7. 屏幕精修方法论（Safe 区 / 背景层次 / 操作栏）

> 本节是 12 号屏（识别引擎设置）精修后的沉淀，供其他 agent 对剩余底部抽屉/模态屏幕（03 快照分析、05 安全详情、09 工具箱、10 对话记录、11 API 日志）执行同等级改进。

### 7.1 三维改进框架

每次精修只围绕三个维度，缺一不可：

| 维度 | 目标 | 一句话原则 |
|---|---|---|
| **① Safe 区** | 顶部状态栏可读、底部不被 Home 条遮挡 | 状态栏浮在遮罩上，抽屉底留 34pt 安全区 |
| **② 背景层次** | 全屏视觉统一、抽屉有质感 | 屏幕底色=抽屉色调深一档，遮罩同色系半透明，抽屉渐变+细描边 |
| **③ 操作栏** | 主次按钮层级清晰 | 操作栏独立于内容流，主按钮品牌色+光晕，次按钮描边弱化 |

### 7.2 ① Safe 区规范

- **顶部**：系统状态栏（`9:41` + `5G 100%`，白字 15/13）作为屏幕首层或 `layoutPosition:"absolute"` 浮于遮罩之上 —— 遮罩压暗背景但状态栏保持清晰（`z` 顺序：遮罩先建，状态栏后建）
- **底部**：抽屉 `padding-bottom: 34`（Home Indicator 高度），操作栏最后渲染于安全区之上
- **拖拽把手**：抽屉顶部居中 44×4 圆角条（`rgba(255,255,255,0.28)`），暗示可下滑关闭；其上留 10pt 呼吸空间
- 屏幕高度改为固定 844（完整手机含刘海/Home 区），不再 `fit_content`

### 7.3 ② 背景层次规范

| 层级 | 做法 | 示例（蓝紫系） |
|---|---|---|
| 屏幕底色 | 抽屉主色调再深一档的深色 | `#0b0b16` |
| 遮罩 | 与屏幕底色同色系的半透明（0.6 左右） | `rgba(8,8,16,0.62)` |
| 抽屉 | 同色系**线性渐变**（顶部亮一档 → 底部深），圆角 20-22，描边 `rgba(255,255,255,0.08-0.09)` | `#232342 → #16162b` |
| 内部卡片 | 半透明白 `rgba(255,255,255,0.05-0.07)` 替代不透明灰，圆角 12-14；关键项加品牌色描边 | `rgba(255,255,255,0.06)` + `rgba(79,195,247,0.25)` |
| 文字 | 不用死灰，用 `rgba(255,255,255,0.4/0.55/0.75)` 分层透明度 | 描述 0.55 / 正文 0.75 / 弱提示 0.4 |

规则：背景色必须"由屏幕→遮罩→抽屉→卡片"逐层递进、同色系、有深度，避免大块纯色平铺。

### 7.4 ③ 底部操作栏规范

- 操作栏从内容流**独立**，置于 1px 分隔线（`rgba(255,255,255,0.08)`）之上
- 双按钮：等宽（`fill_container`）横排，高 48，圆角 12，`gap:12`
  - **主按钮**：品牌色实心 + 外发光阴影（`{type:"shadow",offset:{x:0,y:4},blur:16,color:品牌色@0.35}`）+ 深色文字 700（`#08101f`）
  - **次按钮**：半透明白底 `rgba(255,255,255,0.07)` + 描边 `rgba(255,255,255,0.14)` + 白字 600（0.7 透明度）
- 单一主行动场景（如保存/确认）：主按钮在右或全宽；危险操作（清除/删除）永远为次按钮样式
