## 05 图片解读 · 拍图识别

### 现状结构
Head(BackBtn 44px + 「图片解读」 + 「泰国 · 曼谷」) → PhotoCard(180 高占位) → NameCard(识别结果 + 2 项) → PhraseRow(2 短语卡) → InputBar → Hint → RetakeRow(重新拍摄 / 朗读全部) → SafetyFAB。

### 逻辑交互闭环
- ✅ BackBtn 回 04 相机(SCN-16e 已落地),返回闭环存在。
- ✅ 重新拍摄 → 回 04(重拍),朗读全部 → 播放 2 短语,均有去路。
- ⚠️ **缺口 A(状态)**: PhotoCard 是静态占位(「路牌 / 菜单 / 标牌 照片」),无加载态/失败态。识别中应有骨架/进度反馈,识别失败应有「未识别 · 重拍」出路——当前只有成功态。
- ⚠️ **缺口 B(闭环)**: 短语卡(Phrase1/2)点按「可朗读」(Hint 文案),但无播放态反馈(播放中高亮/进度),操作必反馈红线未覆盖。
- ⚠️ **缺口 C(去路)**: NameCard「已识别 3 项」暗示可展开更多项,但无展开入口,信息截断无出路。
- ⚠️ **缺口 D**: SafetyFAB 常驻 05(SCN-19 保 08 后仍实例化于 05)——安全入口与「正在看图」并存,可接受但需确认点按后无碍当前任务(应抽屉式弹出不跳页,见 safety-drawer-spec)。

### 屏幕语义清晰
- **主意图**: 看图 → 得可用表达。重点信息 = 识别结果(菜单项 + 发音),当前视觉最重的是 180px 空 PhotoCard 占位(图片占位在真实管线中应是照片本身),识别结果 2 行字号 15 与短语卡 13 竞争注意力。
- **重点突出**: 识别结果(NameCard)应是最显眼处——真实照片 + 大字号识别项;短语卡是「下一步可表达」,降为次级。

### 元素精简
- **建议删**: PhotoCard 占位态(真实照片已拍,占位卡只在空态/失败态出现,平时不占 180px);「已识别 3 项」计数若无展开,删计数、保留「识别结果」标签。
- **建议合并**: RetakeRow 两个按钮(重新拍摄/朗读全部)分属「重拍」与「朗读」两种动作,并列易混——「重新拍摄」可收为 PhotoCard 右上角小按钮(照片上覆盖),底部只留「朗读全部」主动作。
- **建议收纳**: 2 短语卡若超过 2 条,改横滑(已有「横滑选择」文案),视觉上弱化为 chips 而非等宽卡。

### 交互闭环缺口汇总
1. 识别中/失败态无反馈无出路(状态闭环缺)。
2. 短语播放无播放态反馈。
3. 「已识别 3 项」无展开入口(截断无出路)。
4. 「重新拍摄」与「朗读全部」并列无主次(动作混列)。

## 06 国家选择(模态)

### 现状结构
mask 模态 → CountryCard(350 宽): GpsRow(「GPS 定位成功 · 泰国 曼谷」+ 定位徽标) → 「选择目的地国家」 → 4 行 8 国卡(38 高,泰国选中=蓝底+2px 深描边+勾选) → 「更多国家 · 26 国 ›」入口 → Profile(「途」头像 + 旅行者 · 简体中文 + 普通话 → 泰语) → ConfirmBtn(「确认并生成安全卡」, r12) → ✕ CloseBtn(mask 右上)。

### 逻辑交互闭环
- ✅ ✕ 关闭(SCN-14b)、确认、选中、更多国家入口,主要闭环齐全。
- ⚠️ **缺口 A**: ConfirmBtn 文案「确认并生成安全卡」与上下文绑定——但 06 同时承担「切换目的地」(从 13 更多页进入)语境,切换时文案应变「切换目的地」,当前无双态(产品审阅已提,未落地)。
- ⚠️ **缺口 B**: GpsRow 文案「GPS 定位成功」仍是技术术语(GPS 属红线禁词,SCN-02 只改了徽标「GPS」→「定位」,主文案漏改)。
- ⚠️ **缺口 C(状态)**: 定位失败(无 GPS)时无降级路径——模态应给「未定位 · 手动选择」弱提示,当前只有成功态。
- ⚠️ **缺口 D**: 选中卡 38px 高 < 44px 触控底线(SCN-13g 精神),8 个可选目标过小。

### 屏幕语义清晰
- **主意图**: 选国家。**次信息过载**——GPS 状态、用户身份(Profile)、语言对三者与「选国」并列,主次混乱。
- **重点突出**: 8 国卡(可选项)应是视觉主体;Profile(旅行者/语言对)是**选择结果预览**不是选择输入,应降级到确认键上方一行弱文案或移除;GpsRow 是状态提示,应收进标题副行。

### 元素精简
- **建议删/收纳**: Profile 行整体(头像 + 用户名)从模态移除——选择模态不该问「你是谁」,语言对「普通话 → 泰语」改为选中后确认键上方一行预览(「普通话 → 泰语」),头像/用户名无用。
- **建议合并**: GpsRow 从独立绿底行 → 并入标题副行(「选择目的地国家 · 已定位 泰国」),省一行高度、降状态噪音。
- **建议提触控**: 8 国卡 38px → 44px(4 行会增高,可减 padding/间距补偿)。

### 交互闭环缺口汇总
1. ConfirmBtn 无双态(首次/切换语境)。
2. GPS 主文案技术术语未清 + 定位失败无降级。
3. 8 国卡触控 <44px。
4. Profile 行冗余,主次不清(选国 vs 身份)。

## 07 安全卡

### 现状结构
TopRow(CloseBtn 32 + CatPill「本地安全指南」+ 「泰国 · 曼谷」 + SAFETY 徽标) → BigArea(求助句大字 + 音标 + 紧急电话) → ActionWrap(朗读求助句 / 安全信息) → DialWrap(3 拨号块: 191 遇到危险 / 1669 身体不适 / 1155 旅游纠纷,各带「长按拨打」) → Hint(「点击安全信息查看完整安全详情」)。

### 逻辑交互闭环
- ✅ 3 拨号块意图化 + 长按拨打提示(SCN-11b/16c 已落地)。
- ✅ 「安全信息」→ 08 详情,朗读求助句 → 播放,均有去路。
- ⚠️ **缺口 A**: CloseBtn 32px(SCN-13g 要求 ≥36~44,05 已 44、08 已 36)——07 作为**独立页**(非模态)是否需要关闭按钮?若 07 是 08 的上游页(08 从 07 进入),则应 BackBtn(chevron-left 回上级)而非 ✕;当前 ✕ 无明确返回目标。
- ⚠️ **缺口 B(状态)**: 拨号长按无进度反馈——长按 0.6s + 进度环 + 震动(红线)在画布无视觉表达,只有「长按拨打」文字提示。
- ⚠️ **缺口 C(去路)**: 求助句大字是「展示给对方」的,但无「递给对方/全屏」入口(03 全屏大字承担此职,07 与 03 关系未定义——07 求助句 vs 03 表达卡全屏)。
- ⚠️ **缺口 D**: 术语漂移——CatPill「本地安全指南」未统一为「安全信息」(SCN-12d 声称统一,画布未落)。

### 屏幕语义清晰
- **主意图**: 紧急时快速求助。重点 = 求助句大字 + 3 意图拨号块。**当前噪音**: SAFETY 英文徽标(禁英文技术感、且与「安全信息」中文重复)、CatPill 与 SAFETY 双标签同义重复。
- **重点突出**: 大字求助句(44px)+ 意图拨号块是核心,两者已达标;顶部三标签(CatPill/位置/SAFETY)挤在一行,抢了核心区注意力。

### 元素精简
- **建议删**: SAFETY 徽标(与 CatPill 重复,且英文违背中文优先);若 CloseBtn 改 BackBtn,TopRow 右端只剩位置。
- **建议合并**: CatPill「本地安全指南」→「安全信息」单标签(术语统一),TopRow = Back + 位置 + 安全信息标签。
- **建议收纳**: 紧急电话(Supplement 行)已列在求助句下方大字区,与拨号块重复(号码两处出现)——Supplement 行删,号码归拨号块。

### 交互闭环缺口汇总
1. CloseBtn 32px 触控不足 + 「关闭」vs「返回」语义不清(07 是页还是模态需定)。
2. 长按拨号无进度环/震动视觉反馈。
3. 求助句无全屏/递出入口(与 03 关系未定义)。
4. CatPill 术语漂移 + SAFETY 徽标冗余 + 紧急号码两处重复。

## 08 安全详情(底部抽屉)

### 现状结构
mask 抽屉 → Sheet(Grabber + SheetHeader「安全详情」+ 位置 + ✕) → Sec1「紧急电话 · 长按拨打」 → PhoneRow(3 电话块 191/1669/1155,各 73 高带长按拨打) → Sec2 求助句(朗读) → Sec3 中国使领馆(使馆名 + 电话) → Sec4 本地提示(电压/饮水/小费 + 防诈骗警示)。

### 逻辑交互闭环
- ✅ ✕ 关闭(mask 右上,SCN-16c)、3 电话块长按拨打、求助句朗读、使馆电话,闭环齐全。
- ⚠️ **缺口 A**: SheetHeader 有 Grabber + ✕,但**无「点遮罩关闭」规范**——mask 点击是否收起未定义(与 safety-drawer-spec 第 2 节「遮罩点击」缺口一致)。
- ⚠️ **缺口 B(去路)**: 使馆/电话块只有号码无「拨号确认态」——长按拨出前无预览(拨错使馆号码成本高),建议长按中进度环 + 松开确认。
- ⚠️ **缺口 C(状态)**: 内容无加载态——抽屉内容若远程拉取(使馆/防诈时效),应有加载骨架/失败重试。
- ⚠️ **缺口 D**: 事件路径缺失(product-cmd P1: 被偷 → 报警 → 补证件 → 联系使馆)——「接下来做什么」半环没补。

### 屏幕语义清晰
- **主意图**: 完整安全信息(阅读面)。**重点 = 紧急电话(第一屏最上)**,已达标;下方求助句/使馆/提示分层清晰(Sec1~4 小标)。
- **噪音**: 本地提示三格(电压/饮水/小费)与紧急内容同屏——电压/饮水属「生活提示」非「紧急安全」,挤占了安全详情的高注意力区(与 product-cmd L2 主动层建议一致,应收敛)。
- **重点突出**: 拨号块 73 高 + 18 号数字已达直给;求助句行、使馆行信息密度合理。

### 元素精简
- **建议收纳**: 本地提示(电压/饮水/小费)从 Sec4 收为折叠区或移出 08(降为次级,防诈骗警示保留——它是安全相关)。
- **建议合并**: Sec2 求助句 + Sec3 使馆行已简洁,保留;但「求助句」在 07 已大字展示,08 内的求助句可降为一行(不重复大字)。
- **建议保持**: 3 电话块、使馆行、✕ 关闭——已达标。

### 交互闭环缺口汇总
1. 遮罩点击关闭未定义(只有 ✕)。
2. 长按拨出无进度环/确认预览。
3. 内容加载/失败态无定义(时效内容可能拉取)。
4. 事件路径缺失 + 本地提示(电压/饮水)与紧急内容同屏抢注意力。
