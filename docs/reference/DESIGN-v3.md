# SceneGo UI 交互设计稿 V3 — 光速回路（路径坍缩版）

> 本文档是 SceneGo **V3 交互设计稿**的结构化描述，与画布 `pencil-new.pen`（V3 画布，5 屏 + 4 组件）完全一致，供设计/编码 agent 直接据此实现。
> * V3 相对 V2 的核心变化：**路径坍缩**——把 13 屏对话式架构压缩为「唯一输入 → 黑箱推理 → 物理扳机」的光速回路，≤ 2 次点击。
> * ⚠️ 沿用 V2 最高红线：① UI 严禁技术/开发术语（TTS/OCR/SOP 等）；② 纯沟通定位，零支付零交易。
> * ⚠️ V3 新增红线：**任何 Action Card 出现之前的元素都不可点击**（除取消/撤回）；**不存在左右切换卡片**；**不存在任务完成页**；**CaptureZone 不得显式标注输入模态（违反寄生原则）**。

---

## 0. 如何使用本文档

- **设计 agent**：在画布上按「§4 逐屏规格」还原 5 屏，复用 §3 组件清单中的 4 个组件。
- **编码 agent**：按「§4 逐屏规格 + §3 组件清单」实现 RN 界面；状态机按「§5 光速回路」重写（见 `src/core/chatSession.ts` 压缩目标）。
- 尺寸单位 `pt`；屏幕画布 390×844（iPhone 级）。深色玻璃拟态（Glassmorphism）。

## 1. 产品上下文（V3 方法论）

**核心命题**：SceneGo 唯一不可替代的两个节点是 **Understand（理解现实）** 与 **Action Card（行动载体）**。其余节点（Capture、Plan、Communicate、Complete、Memory）全部坍缩为这两个节点的属性或瞬态反馈——**不拥有独立页面或状态**。

**四项原则**：

| 原则 | 定义 | SceneGo 落地 |
|---|---|---|
| ① 路径坍缩 | 拿起手机 → 获得 Action Card 之间无任何主动决策点 | 无 Planning 状态；理解期间只显示不可交互的骨架光效（Skeleton Flash），**无"加载中"页面，无状态文字** |
| ② 行动即界面 | Action Card 不是信息容器，而是现实动作的扳机 | 无左右切换；只输出最优解（Emergency > 偏好 > 默认）；卡片唯一主动作 = 对现实产生物理/社会影响的按钮 |
| ③ 副感官寄生 | 相机/OCR/语音识别不作为功能入口，随状态自动激活 | 首页只有万能输入域（悬浮触发区）；语音自动预加载并在靠近耳边/点击卡片空白处时播放；**不显示独立播放按钮** |
| ④ 记忆静默沉淀 | Complete 与 Memory 不产生交互 | 无完成页；沟通结束直接锁屏/回 Idle；Timeline 仅在上滑底部横条 >50% 时作为半屏抽屉出现；**任务完成由系统自动检测，不做为可点击按钮** |

**产品交互公式**：

> **唯一输入（Capture）→ 黑箱推理（Understand）→ 物理扳机（Action Card）**
> 约束：链条 ≤ 2 次点击（1 次触发输入，1 次触发执行）。超过 2 次点击的设计直接废弃。

| # | 组件名 | 画布 id | 说明 | 对应源码 |
|---|---|---|---|---|

### C2 CaptureZone（350×220）

- 玻璃卡：`$bg-glass` 底 + `$border-light` 描边，圆角 32，青色外投影（blur 48）
- **语音 Orb**（84pt 圆）：青色→紫色径向渐变，白 mic 图标，青色辉光（blur 30）——**视觉上唯一的输入触发器**
- 提示：`长按说话 · 晃动拍照 · 轻点输入`（14/600）+ `AI 自动判断输入类型，生成行动卡`（12 muted）
- 交互：单击=唤起语音；长按=按住说话；晃动=拍照；键盘唤起=打字。**禁止显式标注输入模态**

### C3 ActionCard（350×560）

- 顶行：`[🚗 TAXI]` 玻璃胶囊（青色）+ `✕` 关闭（34pt 玻璃圆）
- 中文标题：`出租车按表计费`（18/700）
- **语言块**（高 168，圆角 24）：深色线性渐变底 + 青色→紫色渐变描边；当地语言大字 `TAXI METER PLEASE`（26–34/800 白）→ 音标 `/ˈtæksi ˈmiːtə pliːz/`（13 mono）→ 补充 `按表计费，不是按里程`（12 muted）
- **主扳机**（高 76，圆角 22）：红色线性渐变 `#F87171→#DC2626` + 红色辉光投影；`展示给司机看`（17/700 白）+ `按住触发外放语音 · 全屏大字高亮`（11 白 85%）
- **重试 chips**（浮层，仅重试）：`[🔄 换一种说法]`（红色描边强调）+ `[🔊 再说一遍]`（玻璃常规）
  - ⚠️ **不含"对方听懂了"**——沟通完成由系统自动检测（近距传感器/锁屏/下滑手势），自动结单 + 轻震
- 场景变体（descendants 覆盖）：打车=`展示给司机看`；点餐=`指给店员看`（放大图片）；问路=`播放语音`（外放）

### C4 SkeletonFlash（350×480）

- 顶行：`SCENEGO`（mono 13/800 字距 2）+ 青色脉冲点胶囊（64×20，辉光点）
- 骨架卡（高 260，圆角 24）：3 条渐变 shimmer 条（亮→暗线性渐变）+ **青色光扫线**（横向渐变细线模拟扫描）
- 底部：`[↩ 取消 / 撤回]` 玻璃 pill——**全屏唯一可交互元素**
- 铁律：无 ANALYZING/加载中文字，纯视觉光效

6. **底部 Home 指示条**（134×5）
7. 背景：靛蓝→深空径向渐变（顶部 `#141428`）

### 02 CAPTURING 采集态（390×844）— 瞬态覆盖层

- 全屏真实相机预览（曼谷街头夜间出租车实拍图）+ 顶部/底部黑色渐变 scrim
- 状态栏实例覆盖顶部
- **取景框**（280×240，居中，圆角 18）：白描边 + 四角青色 L 形括号（发光）+ 引导文案 `对准菜单 / 标牌 / 标志`（15/600）+ `自动对齐画面中的文字区域`（12 白 70%）
- **底部控制条**（668→844）：`✕` 取消（50pt 玻璃圆）｜ **SNAP**（外白环 76pt 4px + 内红 58pt + 白相机图标）｜ `⚡` 闪光（50pt 玻璃圆）
- `单击拍照 · 自动识别并生成行动卡`（11 白 60%）
- 交互：单击 SNAP 即推理；单击 ✕ 回 Idle

### 03 SKELETON FLASH 推理态（390×844）— 瞬态覆盖层

- 整屏 = C4 实例（350 宽，居中）
- 铁律文案：`🔒 交互铁律：Action Card 出现前禁一切点击（仅撤回保底）`（11 muted）
- 唯一可交互 = 取消/撤回 pill

### 04 ACTION CARD 行动卡（390×844）— 交付终端

- 整屏 = C3 实例（350 宽，居中）
- 提示：`点击卡片空白处或靠近耳边，自动播放语音`（11 muted）
- 背景：暗红→深空径向渐变（顶部 `#1E0E22`）
- 沟通成功 → 系统自动检测结单回 Idle

### 05 TIMELINE 记忆抽屉（390×520）— 寄生抽屉

- 强玻璃 sheet（`$bg-glass-strong`，圆角 32，上投影）：44×5 手柄 + `历史对话`（17/700）+ `✕`
- 历史项 ×4（`$bg-card` 圆角 16）：40pt 图标底（彩色 lucide 图标）+ 标题（14/600）+ 时间（mono 11 muted）+ `›`
  - `🚗 出租车按表计费 · 今天 11:24`
  - `🍽 菜单推荐 · 冬阴功 · 今天 09:10`
  - `🗺 问路 · 大皇宫 · 昨天 18:02`
  - `🧾 退税 · 机场 VAT · 昨天 13:45`
- 点历史项 → 恢复 Action Card。**绝不出现在 Action Card 下方或常驻信息流**

## 5. 光速回路状态机（压缩版）

```
                  ┌─────────────────────────────────────────────┐
                  │                                             │
   ┌──────┐ 输入  ┌─────────┐      ┌──────────────┐ 最优解   ┌──────────────┐
   │ IDLE │─────▶│CAPTURING│─────▶│ SKELETON     │─────────▶│ ACTION CARD  │
   │(理解态)│      │(采集瞬态)│      │ FLASH(黑箱)  │          │(行动扳机)     │
   └──────┘      └─────────┘      └──────────────┘          └──────┬───────┘
      ▲              │ 取消              │ 取消/撤回                  │ 系统检测完成
      │              └──────────────────┴────────────────────────────┘
      └─────────────── 回到 Idle（任务结束，无完成页）──────────────────┘
```

**状态定义（全部为瞬态或属性，无独立页面）**：

| V2 节点 | V3 去向 |
|---|---|
| Planning / Communicating 页面 | 删除。坍缩为 Skeleton Flash（禁交互）+ Action Card 浮层化建议回复 |
| 三模态入口（拍/说/打字按钮） | 合体为 CaptureZone 悬浮触发区，**不显式标注输入类型** |
| 卡片左右切换 | 删除。只输出最优解，不满意退回重拍/重说 |
| Completed 页面 | 删除。系统自动检测完成（传感器/手势）+ 自动回 Idle |
| Timeline（历史流） | 半屏抽屉，仅上滑 >50% 触发 |
| 新手引导/设置页 | 删除。GPS + 首次输入图片自动判定 |

**点击计数审计**：输入（1 次）→ 执行（1 次）= 2 次，**达标**。结单、历史恢复、换说法均为 0 次额外点击。

## 6. 实现约束与建议

### Pencil / 设计画布
- 每屏 390×844、`clip:true`；屏幕背景用径向渐变（顶部环境光色 → `#050508`）
- 渐变描边：`stroke` 支持 `{type:'gradient'}`（语言块边框用）
- 图标一律 lucide 库；辉光用 `effect: {type:'shadow', blur: 30–60}`
- 组件置顶排列，屏幕在下 2×2+1 网格排列

### React Native 实现
- **状态机**：`chatSession.ts` → `phase: 'idle' | 'capturing' | 'inferring' | 'action'` + `card: CardData | null`
- **输入**：`capture()` 单入口（语音 + 拍照 + 文字统一路由，系统自判类型）
- **输出**：`ExprCard` 重构为 C3 ActionCard（单扳机）；`FlashCardView` 保留全屏高亮交付层
- **删除**：`TabBar`（四 Tab）、`ChatPage`（对话流）、`CardStackPage`、`NotesPage`、`MorePage`
- **新增**：`SkeletonFlash`（禁交互骨架）、上滑抽屉（>50% 阈值）、近距传感器监听（自动结单）
- **手势**：CaptureZone 单击/长按/晃动；Action Card 空白点击=语音播放、靠近耳边=自动播放
- **视觉**：线性渐变按钮、径向渐变背景、玻璃拟态（`rgba` + 细描边）、辉光投影（`shadowColor` 带透明度）
