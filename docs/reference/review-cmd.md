# SceneGo 交互设计审阅意见(6 屏 + 全局组件)

> 审阅对象:`docs/reference/DESIGN-v2.1.pen`(Pencil 画布,13 屏已设计完整)
> 审阅范围:06 国家选择 / 07 安全卡 / 08 安全详情 / 09 位置切换提示 / 10 离线包状态 + 全局组件(StatusBar / TabBar / ExprCard / InputBar)
> 设计红线:①纯黑极简、无 emoji、图标用文字/lucide;②界面文案禁用技术术语;③禁止上滑手势触发;④任何操作必须有即时反馈 UI;⑤不造假数据、全真实管线;⑥安全卡大数字拨号要直给、防误触。

## 全局组件

### StatusBar
- **现状缺陷**:无。时间/5G/电量是标准结构。
- **改进建议**:04 相机屏为深色底时文字颜色需随屏切换;若所有屏统一深底则无需改动。
- **视觉调整**:保持现状。

### TabBar(卡栈 / 对话 / 笔记 / 更多)
- **现状缺陷**:
  1. 仅"对话"有选中态,切 tab 无按压/切换动效;"卡栈"与"对话"边界语义不清(卡栈是否就是对话里的卡片?),用户易困惑。
  2. 无角标能力(离线包可更新、有未读会话时无红点提示)。
  3. 底部 56px 高度在 iPhone 全面屏上会被 Home Indicator 遮挡,无安全区预留。
- **改进建议**:
  1. 明确 tab 语义:若"卡栈"= 主入口,建议合并为 3 tab(卡栈/笔记/更多),或把"对话"改名"翻译",避免双入口歧义。
  2. 为每个 tab 图标右上角预留角标位(6x6 圆角矩形,accent-red),供"离线包可更新"等提示使用。
  3. TabBar 容器底部加 24px 安全区 padding,防止内容被 Home 条遮挡。
- **视觉调整**:选中 tab 图标+文字用 accent-blue、未选中 text-tertiary(现状正确);建议选中指示条从顶部 2px 改为 16x3,并加 0.2s 位移动画。

### ExprCard 表达卡
- **现状缺陷**:
  1. 唯一动作"播放语音"没有播放中状态:点击后无 loading/波形动画/再次点击停止,用户无法确认是否在播。
  2. "全屏 ›"入口无按压态、无对应全屏页反馈;全屏页"点击 ✕ 返回 · 点按关闭"是提示文案而非状态。
  3. 无"重新生成/换个说法"入口 —— 表达不当时只能退出重来。
- **改进建议**:
  1. 播放态三态:待播(volume-2 灰)→ 播放中(图标变 accent-blue + Phonetic 行出现 3 格呼吸条动画或文字亮度提升)→ 播放完回待播;播放中再点一次停止。
  2. "全屏 ›"点击后全屏页带"1/1"进度(已有),hint 改为"点击卡片可放大查看 · 点击 ✕ 返回";放大态点击卡片任意处关闭。
  3. 增加"换一句"文字入口(rotate-ccw 图标 + "换一句"):点击进入 loading(卡片整体 30% 透明度 + 顶部细进度条),生成完成后替换内容 —— 满足红线 4。
- **视觉调整**:播放中时 BigArea 边框从 #ffffff33 提亮至 #ffffff66;"换一句"loading 时底部加 2px accent-blue 无限滚动进度条。

### InputBar 输入条
- **现状缺陷**:
  1. 发送按钮常亮,空输入时可点但无效果 → 违反"操作必有反馈"。
  2. 相机/麦克风按钮点击无权限处理流程:未授权时点了没反应。
  3. placeholder"说出需求 / 打字 / 拍照..."与触发区文案重复,且暗示三种方式无优先级。
- **改进建议**:
  1. 发送按钮空态禁用:fill 降为 bg-card-light、图标 text-tertiary;有内容时变 accent-blue。发送后按钮进入 loading(图标换转圈)直至卡片生成完成,同时禁用重复发送。
  2. 相机/麦克风首次点击若未授权:先显示一次内联说明(按钮变黄 1s,提示"需要相机权限,请在系统设置中开启")。
  3. placeholder 简化为"输入你想说的话…",拍照/语音入口留给两侧图标与触发区,减少重复。
- **视觉调整**:发送按钮 40x40 保持;loading 态用 14px 环形 spinner(stroke 2,蓝底上 #0a0a1e)。

## 06 国家选择
- **现状缺陷**:
  1. **红线 1 违例**:国旗全部是 emoji(🇹🇭🇯🇵🇰🇷🇻🇳🇸🇬🇲🇾🇮🇩🇱🇦),头像 🧳 也是 emoji。
  2. 列表只放 8 国,与"26 国离线可用"不一致,无滚动/查看更多入口,其余 18 国无从选择。
  3. GPS 行只有"成功"一种状态;未授权/定位中/定位失败无对应 UI(红线 4)。
  4. 泰国卡片默认蓝色填充,但无明确"已选中"标记(对勾/描边),选中切换逻辑未定义。
  5. 确认按钮"确认并生成安全卡"是异步动作,无按压态/loading/成功结果,点击后直接跳转无反馈。
  6. Profile 行"旅行者 · zh-CN"里 zh-CN 是 locale 代码,属技术味文案(红线 2);"普通话 → 泰语"语言对不随所选国家联动。
- **改进建议**:
  1. emoji 旗替换为 26x18 圆角矩形内两字母国家码(TH/JP/KR…,等宽 mono 字体),或统一 lucide `globe` 图标 + 国家名;头像 🧳 改 lucide `briefcase`。26 国统一此规则。
  2. 卡片区改为可滚动网格(2 列、26 项),隐藏滚动条;当前国家(泰国)置顶。
  3. GPS 行四态:GpsRow 文案随状态切换 —— 定位中("正在定位…" + 图标旋转)、成功(现状)、失败("定位失败,请手动选择" + 图标变 accent-yellow)、未授权(同失败并附"前往设置")。每态颜色随语义变(green→yellow/red)。
  4. 选中态:卡片加 2px accent-blue 描边 + 右下角 16x16 蓝色圆内白勾(check);点击其他卡片时旧卡回退 bg-card-light。
  5. 确认按钮:按压态(scale 0.98 + 亮度降低)→ loading("生成安全卡中…" + spinner,按钮禁用)→ 成功跳转 07;失败显示"生成失败,请重试"内联提示(按钮下 12px 红色小字)。
  6. 语言对联动:选中日本后 Profile 行实时变为"普通话 → 日语";zh-CN 改为"简体中文"。
  7. 空态:若离线包未下载完,未覆盖国家卡片角标加"未下载"灰字,点击提示"需联网下载后使用"。
- **视觉调整**:GPS 行定位中时 map-pin 图标加旋转动画;确认按钮 loading 时文字换"生成中…"、按钮底色降 10% 亮度;选中卡片蓝色描边 2px,其余 1px border-subtle。

## 07 安全卡
- **现状缺陷**:
  1. 三大数字拨号块点击即拨?设计未定义防误触 —— 紧急号码误触成本极高(红线 6 未落实)。
  2. 拨号块无按压态、无"正在拨打/已挂断/拨打失败(无 SIM/无信号)"反馈(红线 4)。
  3. "朗读求助句"无播放中状态;若与拨号同时进行会抢音频焦点。
  4. 大数字"โปรดช่วยฉันด้วย"仅一句,紧急场景下表达单一,无第二句备选(如"请带我去医院")。
  5. 底部 hint 指向 08,但 08 是底部抽屉,跳转关系未说明(点击后弹出抽屉还是新页?)。
- **改进建议**:
  1. **防误触方案(推荐)**:长按 0.6s 拨号 + 松手前滑动取消。拨号块标注"长按拨打"小字;按压 0.6s 内显示环形进度(描边渐满),松手即取消;满 0.6s 触发系统拨号并伴随震动反馈。误触判定:0.6s 内松手无任何操作。备选:轻点后弹 3 秒倒计时确认条("191 警察 · 3 秒后拨打 / 取消"),倒计时内点取消即中止。
  2. 拨号状态反馈:触发后按钮文字变"正在拨打…";若系统返回失败(无拨号能力),按钮变红显示"无法拨号,请手动拨打 191" + 数字放大可复制。
  3. 播放态三态(同 ExprCard):待播/播放中(图标变绿+呼吸动画)/停止;播放时若有备选句,卡内加左右切句入口(chevron + "2/3")。
  4. 明确 07→08 跳转:点击"安全信息"为**滑出底部抽屉**(非新页),08 标题处带关闭按钮。
  5. 朗读/拨号互斥:进入拨号流程时自动停止朗读。
- **视觉调整**:拨号块按压时底色从 accent-green-bg 提亮至 0.4 透明度并加 2px green 描边;长按进度环画在数字上方(16px 高,stroke 2);"长按拨打"提示字 9px text-muted 置于每个拨号块数字下方。

## 08 安全详情(底部抽屉)
- **现状缺陷**:
  1. **红线 3 风险**:底部抽屉的"展开/收起"若靠上滑手势实现则直接违例;5 个分区内容在 390x844 上必然超屏,无滚动方案定义。
  2. 拨号方块与使馆电话仍"点击即拨",无防误触(同 07)。
  3. 求助句仅一条、可播放但无状态;无更多求助句。
  4. 本地提示(电压/饮水/小费)是纯静态卡片,无任何动作价值 —— 看到"220V"无法进一步表达。
  5. 防诈骗是纯警示文字,没有"行动"出口:提示→生成求助卡/报警的链路断裂。
  6. 抽屉高度无上限定义,小屏(如 SE)上内容会被截断。
- **改进建议**:
  1. **展开方式**:由 07"安全信息"按钮**点按**滑出(入场 0.25s 上移 + 背景 mask 渐显);抽屉内部滚动用**普通纵向滚动**(非上滑手势),顶部 Grabber 仅作视觉提示;**收起** = 点击 mask / 点按抽屉顶部关闭按钮(或点按 grabber),不用上滑。红线 3 落实为:全 App 无任何"上滑触发"动作。
  2. 抽屉高度上限 85% 屏高,内容超出部分内部滚动;5 个分区固定顺序。
  3. 拨号防误触与 07 统一(长按 0.6s),三个号码块 + 使馆电话同一交互;使馆电话点击后同样进入确认流程。
  4. 提示行增加"说给当地人听"能力:电压行点按后弹出小表达卡气泡(当地语言"电压是多少?"),饮水/小费同理 —— 让静态信息可转化为表达卡(与产品核心闭环一致)。
  5. 防诈骗区底部加行动按钮:"生成求助表达卡"(生成"请帮我联系警察"卡,跳转全屏展示)+ 右侧"拨打 191"小字入口(长按规则同上),完成"提示→行动"链路。
  6. 求助句区改为横滑卡片组(3 条:请帮帮我 / 请带我去医院 / 我被骗了,各自可播可复制)。
- **视觉调整**:抽屉圆角 16 上沿不变;分区标题(紧急电话/求助句/中国使领馆/本地提示)前加 lucide 小图标(phone / volume-2 / landmark / lightbulb)增强扫描性;防诈骗区从红底卡片升级为左侧红色竖条 + 白底,行动按钮用 accent-red 文字按钮。

## 09 位置切换提示
- **现状缺陷**:
  1. 触发时机未定义:位置变化检测是持续定位还是进入前台检测?权限未授权时此弹窗永不出现,用户也无主动改位置的入口。
  2. "保持"后是否记住?每次检测都弹会变成骚扰;若记住,则无法手动改回。
  3. "切换"是异步动作(切换安全卡+语言需加载新国家包),无 loading/成功反馈;目标国离线包未下载时,切换后直接失去离线能力 —— 未预警。
  4. 弹窗无 mask 点击关闭/取消语义;"保持"与"切换"按钮尺寸相同,误触概率高。
  5. 文案"当前安全指南基于 泰国 · 曼谷"中"安全指南"与 07/08 的"安全信息"用词不一致。
- **改进建议**:
  1. 触发策略:**仅在前台启动且距上次提示 >24h** 时弹出一次;定位权限未授予时,在 06 国家选择 GPS 行提示"未开启定位,请手动选择"(与 06 建议 3 统一)。同时 01 首页位置行作为**主动切换入口**,点开即进 06 国家选择。
  2. "保持"点击后:弹窗关闭 + 状态持久化(记住当前选择),并在 01 首页位置行旁短暂显示 2s toast"已保持 泰国 · 曼谷";位置行 chevron 提供"位置已变,点此切换"常驻入口。
  3. "切换"点击后:按钮进入 loading("切换中…" + spinner,禁用);若目标国离线包未下载,先弹第二层确认"日本离线包未下载,切换后需联网使用,仍要切换?"(确定/取消)。成功 toast"已切换至 日本 · 东京";失败(包下载失败)回滚原国家 + 红色错误提示。
  4. 视觉降误触:"保持"为次按钮(bg-card-light),"切换"为主按钮(accent-blue,高度 46),间距 10px 保持。
  5. 文案统一:全 App 用"安全信息"一个词;弹窗描述改为"当前安全信息基于 泰国 · 曼谷,检测到你在 日本 · 东京,要切换吗?"
- **视觉调整**:切换按钮 loading 态同 06 确认按钮(spinner + 禁用);新增的第二层确认弹窗复用本卡样式(330 宽、16 圆角、红色警示行)。

## 10 离线包状态 · 26 国
- **现状缺陷**:
  1. **数据不一致**:Summary 标"26/26",但列表只画了 13 国,且整页无滚动区定义 —— 26 行必然溢出(红线 5:不造假)。
  2. 列表行只有"已下载 ✓"一种状态;无"更新中/待更新/失败"状态展示(红线 4)。
  3. "检查更新"按钮无 loading、无结果反馈;底部 hint"已是最新"是写死文案,未联动按钮结果。
  4. 版本号(v3.2/v3.0)直接给用户看,技术味(红线 2);"场景包按月自动更新"与"检查更新"并存,用户不知道听谁的。
  5. 行无点击行为;无删除/按需下载管理能力,与 26 国全量 128MB 占用无优化出口。
  6. 128MB、26/26、v3.2 均为静态样例,无真实管线标注(红线 5)。
- **改进建议**:
  1. 列表改为**可滚动列表**(26 项),排序:当前所在国置顶、其余按字母;Summary 卡固定不滚动。空态(0 国下载)时列表区显示"尚未下载离线包,联网后自动下载"占位。
  2. 行状态四态 + 对应动作:
     - 已就绪(✓ 绿)
     - 更新中(spinner 旋转 + "更新中…",禁用行)
     - 可更新(黄色圆点 + "更新"文字按钮,点击进入下载)
     - 失败/未下载(灰 + "重试"按钮,点击重新下载)
     每行点击展开该国详情(紧急号码预览 + 已用空间)。
  3. "检查更新"按钮流程:点击 → loading("检查中…")→ 两种结果:无更新 → 按钮下 toast"已是最新";有更新 → 按钮变 accent-blue("更新 3 国")可一键全更 + 逐行黄色更新点。失败(断网)→ 红字"网络不可用,请联网后重试"。
  4. 版本号对用户无意义:行右侧改为"上次更新 07-20"日期;Summary 的"场景包 v3.2"改为"数据版本 2026-07"。
  5. 增加管理入口:底部"检查更新"旁加"管理"文字按钮,进入管理页点选删除;删除前弹确认"删除 日本 离线包?(离线时无法使用该国服务)"(红线 3 禁横滑手势,故不用左滑删除)。
  6. 所有数字标注"(示例数据)",交付时接真实管线。
- **视觉调整**:Summary 图标从 database 换 lucide `package-check`;行高 52px;更新中 spinner 用 12px accent-blue 圆环;可更新行左侧加 6px accent-yellow 圆点。

## 跨屏共性问题(汇总)
1. **红线 1 违例**:06 屏全部国旗 emoji + 🧳,须替换为两字母国家码徽章或 lucide 图标。
2. **红线 2 违例**:`zh-CN`(06 Profile)、`GPS` 徽标(06)、`v3.2` 版本号(10)三处技术文案,分别改"简体中文 / 定位 / 日期"。
3. **红线 3 落实**:08 抽屉"展开=点按、收起=点 mask 或关闭钮、内部滚动=普通滚动";全 App 无上滑触发。
4. **反馈缺失最严重处**:拨号(07/08)、播放(所有)、确认(06)、检查更新(10)、发送(InputBar)—— 统一建议:按压态 + loading spinner + 成功/失败内联提示三件套。
5. **拨号防误触**:建议全局统一"长按 0.6s + 进度环 + 震动确认",比二次确认弹窗更符合紧急场景"直给"要求。
