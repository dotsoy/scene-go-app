# SceneGo V3.1 产品交互稿 — 极致三步直达版

> 本文档是 SceneGo **V3.1 产品交互稿**，与 Pen.app 画布 `pencil-new.pen`（6 组件 + 6 屏纯粹主流程故事板）100% 同步。  
> **核心演进**：彻底删除一切无谓的冗余步骤屏（独立「拍照屏」、「黑箱骨架屏」、「FlashCard 全屏屏」及主流程内的「Timeline 复活屏」）。打车主流程收扣为**极致 3 步闭环**（输入 ──⚡──▶ 说出 ──▶ 听懂）。

---

## 1. 产品公式与三步直达架构

### 1.1 产品公式

```
用户输入（任意形式，最终落地为文字）
        ↓
   【黑箱】理解场景 + 判断方向（卡片原地闪烁占位 ⚡ 零独立切页）
        ↓
   ┌────┴────┐
   ▼         ▼
理解环境    与人沟通
   ▼         ▼
Insight    Action Card（双向回路）
（只读）    说出 ──▶ 听懂 ──▶ 完结回 Idle
```

## 5. 原地闪烁态规格（In-Situ Shimmer）

| 项 | 规格 |
|---|---|
| 触发时机 | 用户提交输入（语音/照片/文字）后，卡片原位置立即进入闪烁态 |
| 时长上限 | ≤1.5s；超过 2s 显示「理解中…」进度兜底提示 |
| 视觉 | 回显胶囊（`已接收…`）先于卡片出现；卡片区域显示高对比度青紫渐变骨架条 + 扫描光效 |
| 可交互元素 | 仅「取消/撤回」胶囊（右下角）；其余元素一律不可点击（交互铁律） |
| 结束 | 闪烁结束自动变现实卡（Action Card / Insight），无任何切页 |

**画布体现**：02 屏 / 05 屏卡片区域叠加 `⚡ 原地闪烁 ≤1.5s` 过渡带（骨架条 + 取消胶囊）；C3 SkeletonFlash 为闪烁态组件原语（非独立屏）。

## 6. 手势冲突解决方案（阈值化）

| 手势 | 触发区域 | 触发阈值 | 优先级 |
|---|---|---|---|
| 上滑展开相机 | Idle 屏顶部 y < 120px | 上滑位移 > 40px | 与 Timeline 同时满足时相机优先 |
| 上拉 Timeline 抽屉 | Idle 屏底部 y > 700px | 上滑位移 > 50% 屏高才展开；< 50% 回弹 | — |
| 中部滑动 | 120px ≤ y ≤ 700px | 不触发任何手势（仅内容滚动） | — |

- **区分机制**：滑动起始区域（顶部 vs 底部）+ 位移阈值（40px vs 屏高 50%）
- **防误触**：任一区域手势未达阈值即回弹，无状态残留
- **画布体现**：01 屏叠加热区 overlay（青色顶部区 / 紫色底部区 / 中性中部区）

## 7. 泳道对称性说明

- **泳道一（沟通回路）**：针对"与人沟通"场景，强调双向互动（说出 → 听懂 → 完结），3 步线性闭环
- **泳道二（只读解读）**：针对"环境理解"场景，强调单向信息获取（拍照 → 解读 → 点餐），带异常分支
- **设计意图差异**：泳道一注重对话延续性与快捷回复，泳道二注重识别准确性与纠错兜底
