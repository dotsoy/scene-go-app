# SceneGo 按钮流程闭环审计

基于产品核心承诺：秒级成卡、离线可用、精准表达。纯黑极简、无 emoji、禁技术术语、操作必反馈。

---

## 01 IDLE 待机

### 1. HoldMic（按住说话）
1. **点击后动作**：激活麦克风，开始录音
2. **下一状态**：录音中实时波形反馈 → 松手停止录音 → 自动触发成卡
3. **异常路径**：麦克风权限拒绝 → 显示「需要麦克风权限」的引导；录音超时 30 秒 → 自动停止并提示「请说得简洁」
4. **闭环情况**：✅ 完全闭环
5. **补全建议**：P1 - 添加「长按 3 秒可取消」的撤销机会

### 2. InputBar 相机按钮
1. **点击后动作**：激活内联相机模式
2. **下一状态**：**04 内联相机** → 取景框浮现
3. **异常路径**：相机权限拒绝 → 显示「需要相机权限」的快捷设置入口
4. **闭环情况**：✅ 闭环
5. **补全建议**：P0 - 若相机权限被永久拒绝，显示「联系设置 → 启用相机」的深层指引

### 3. InputBar 发送按钮
1. **点击后动作**：提交文字输入，触发成卡
2. **下一状态**：**02 表达卡** → 全屏展示
3. **异常路径**：无网络 → 离线模式；空内容 → 按钮灰显
4. **闭环情况**：✅ 闭环
5. **补全建议**：无；但可P1：添加「输入太短，确定要发送吗？」的确认态

## 02 表达卡

### 1. 播放按钮
1. **点击后动作**：播放表达式卡的当地语言语音
2. **下一状态**：语音播放 → 显示波浪动画；播放完成自动返回播放态
3. **异常路径**：语音下载失败 → 静音显示「无法播放」；无语音权限 → 提示「前往设置」
4. **闭环情况**：✅ 闭环
5. **补全建议**：P1 - 播放时添加「10 秒倒计时」的可见反馈，防止用户误触停止

### 2. 重播按钮
1. **点击后动作**：重新生成相似表达卡
2. **下一状态**：加载动画 → 新卡片渐显
3. **异常路径**：AI 模型不可用 → 显示「稍后重试」；同一卡片 3 次重播 → 提示「已到达上限」
4. **闭环情况**：⚠️ **存在闭环缺口**：没有「放弃重播」的中途退出
5. **补全建议**：P0 - 加载动画中添加「X 取消」按钮，点击后返回当前卡片

### 3. 建议回复按钮
1. **点击后动作**：选中该建议，准备发送给对方
2. **下一状态**：按钮变浅+勾选图标 → 侧滑出「发送/复制」的快捷操作
3. **异常路径**：无网络 → 显示「已离线，无法发送」；复制失败 → 提示「长按即可复制」
4. **闭环情况**：⚠️ **存在闭环缺口**：没有「反选」的快速回退
5. **补全建议**：P1 - 勾选后，点击非按钮区域即可取消选中，显示「取消已复制」的微反馈

### 4. 全屏按钮
1. **点击后动作**：放大当前卡片，进入沉浸式阅读
2. **下一状态**：卡片平滑放大至全屏
3. **异常路径**：无异常路径（放大本身不依赖外部资源）
4. **闭环情况**：✅ 闭环
5. **补全建议**：P0 - 全屏后添加「缩小»«»的按钮，防止用户困 trapped 模式

### 5. 安全链接按钮
1. **点击后动作**：跳转到「安全表达」模式
2. **下一状态**：加载「安全卡」作为替代表达
3. **异常路径**：没有安全卡素材 → 显示「临时安全表达」；网络中断 → 缓存最近的安全卡
4. **闭环情况**：⚠️ **存在闭环缺口**：没有「返回原卡」的快捷方式
5. **补全建议**：P1 - 安全卡顶部添加「← 返回原表达」的可见按钮

## 03 全屏大字

### 1. 关闭按钮
1. **点击后动作**：退出全屏，返回**02 表达卡**
2. **下一状态**：卡片收缩回原位
3. **异常路径**：无异常路径
4. **闭环情况**：✅ 闭环
5. **补全建议**：P0 - 关闭动画添加「快速关闭」的触觉反馈（轻微震动）

### 2. 播放按钮
1. **点击后动作**：播放当地语言语音
2. **下一状态**：波浪动画 + 语音播放
3. **异常路径**：同 **02 播放** 的异常路径
4. **闭环情况**：✅ 闭环
5. **补全建议**：同步 **01 IDLE** 中的 10 秒倒计时建议

### 3. AI 按钮
1. **点击后动作**：查询该表达卡的扩展解释
2. **下一状态**：加载「细节层」 → 显示中文释义/近义词/例句
3. **异常路径**：无网络 → 显示「离线模式：暂无细节」；查询超时 3 秒 → 返回「稍后更精准」
4. **闭环情况**：⚠️ **存在闭环缺口**：细节层弹出后，没有「收起」的明确按钮
5. **补全建议**：P0 - 细节层顶部右侧添加「▼ 收起」的指示器，点击收起，或下滑退出

### 4. 下一步按钮
1. **点击后动作**：加载下一张概率最高的表达卡
2. **下一状态**：卡片左滑出 → 新卡片滑入 → 动画完成
3. **异常路径**：没有下一张 → 显示「没有更多推荐」；加载失败 → 显示「重试」按钮
4. **闭环情况**：✅ 闭环
5. **补全建议**：P2 - 添加「← 上一张」的后退功能，防止用户错过想表达的卡片

### 5. Swipe（滑动）
1. **点击后动作**：水平滑动切换卡片
2. **下一状态**：卡片平滑滑动至相邻位置
3. **异常路径**：滑动距离过小 → 动画回弹到中心；滑动卡住 → 返回中心
4. **闭环情况**：✅ 闭环
5. **补全建议**：P1 - 滑动时添加「可滑切换」的轻微反馈动画，引导用户意识到了滑动功能

## 04 内联相机

### 1. 取消按钮
1. **点击后动作**：退出相机模式，返回**01 IDLE**
2. **下一状态**：相机视图消失，回到文字/语音入口
3. **异常路径**：无异常路径
4. **闭环情况**：✅ 闭环
5. **补全建议**：P0 - 取消时添加淡出动画，避免画面突然消失的突兀感

### 2. 快门按钮
1. **点击后动作**：拍摄当前照片，触发识别
2. **下一状态**：照片淡入 → 识别加载 → **05 图片解读**
3. **异常路径**：照片模糊 → 提示「请靠准星对准物品」；识别失败 → 显示「重新拍摄」
4. **闭环情况**：✅ 闭环
5. **补全建议**：P1 - 快门按钮点击时添加「快门声」的震动反馈，模拟实体快门感受

## 05 图片解读

### 1. 重拍按钮
1. **点击后动作**：退出识别，进入**04 内联相机**
2. **下一状态**：相机取景框恢复
3. **异常路径**：无异常路径
4. **闭环情况**：✅ 闭环
5. **补全建议**：P0 - 重拍按钮点击时添加「返回」的左上角小箭头动画

### 2. 播放全部按钮
1. **点击后动作**：朗读所有识别结果（物品名 + 短语）
2. **下一状态**：顺序播放每个短语 → 显示播放进度条
3. **异常路径**：播放被静音 → 提示「前往设置开启语音」；播放超时 → 自动停止
4. **闭环情况**：⚠️ **存在闭环缺口**：播放中没有「暂停/停止」的控制
5. **补全建议**：P0 - 播放界面顶部添加「⏸️ 暂停」按钮，点击后停止播放并返回当前卡片

## 闭环设计原则

### 1. X 中止必备
任何耗时操作（加载、播放、转换）都要添加「X 中止」的明确入口。用户在表达场景中焦虑，必须随时掌控节奏。

### 2. 返回上一步快捷
从深层次功能（安全卡、AI 细节、播放全部）返回前卡，都要提供「← 返回」的按钮。出境用户时间紧迫，回退路径要直线。

### 3. 反馈视觉化
每次从一种态切换到另一种态，都要有明显的视觉/触觉反馈（动画/震动/颜色变化）。出境用户多在不利光线下使用，反馈必须足够显眼。

### 4. 空态占位
所有按钮在触发失败时的「空态」都要有温和的、可操作的提示，绝不制造用户停滞。离线场景是常态，不是例外。

### 5. 误触防护
功能越敏感操作（重播、播放全部、全屏、关闭）都要设计「防误触」机制：按压后倒计时、滑动激活、二次确认等。
