# SceneGo V3.1 产品需求文档 (PRD)

> 视觉与设计令牌继承既有文档 `docs/reference/DESIGN.md`。

## 1. 核心架构变更

- **废除底部 Tab 栏**：彻底移除 V2 时代的底部 4-Tab 导航栏（卡栈/对话/笔记/更多），全界面收扣为单一纯粹的随身工具。
- **独立 Action Card 流式对话**：沟通流中的每一轮表达（用户发起、对方回复）均为**平铺独立的 Action Card**，卡片结构统一且高度解耦。
- **推荐回复并列水平滑动**：系统推荐回复选项（Action Card 3a/3b/3c）采用**横向并列平滑卡片行**，用户可横向滑动浏览选择。
- **Insight 表达卡并列水平滑动**：图像场景解读中的扩展实用表达卡（Insight Card A/B/C）同样采用**横向并列平滑卡片行**，维持与沟通流高度统一的交互语言。
- **mic ON 集成打字入口**：卡片流底部在呈现 `mic ON` 麦克风开启状态的同时，右侧集成常驻 `打字补充说明...` 输入框与发送按钮，支持随时打字补充。
- **保留独立语音播放**：每个语音 Action Card 右下角保留极简 `PLAY` 播放按钮，可独立重播任意一轮历史语音。
- **纯粹文本上下结构**：
  - 上面：展示给对方看的当地语言大字（白色高对比）
  - 下面：用户母语确认含义（黄色辅助字）
  - 去除一切拼音读音、预设分类标签、回显胶囊与「完成」按钮。
- **展示模式**：点击任意 Action Card 进入全屏高对比度大字展示，点击任意区域退出。

## 2. 页面与交互状态

交互草图见 `docs/reference/DESIGN-v3.1-wireframe.tldraw` 及 Pen.app 画布 `docs/reference/DESIGN-v3.1.pen`。

1. **核心入口 (Idle)**：顶部定位语言胶囊（`曼谷 · 泰语`）、`上滑展开相机` 把手、中央按住说话 Orb、底部常驻输入框（`说出需求 / 打字 / 拍照...` >）。
2. **沟通卡片流 (Action Cards)**：上下结构（外语上/母语下），多轮对话流中每个节点（用户表达卡 1、对方回复卡 2）均为独立平铺 Action Card（带 `PLAY` 按钮），推荐回复为横向并列滑动卡片行（卡片 3a/3b/3c），底部为 `mic ON` + 打字补充输入栏。
3. **图像场景理解 (Insight)**：
   - 顶部展示用户实拍照片缩略图；
   - 核心识别主卡（全宽 350pt）：当地叫法/核心标识，外语在上面（白色）、母语在下面（黄色）；
   - 扩展实用表达与建议卡：采用**横向并列滑动卡片行**（卡片 A/B/C），保持统一上下结构；
   - 异常时原位置展示 `画面模糊，未看到有效信息` 并提供 `重新拍摄` / `手动打字输入`。
