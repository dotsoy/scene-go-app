# SceneGo 产品层交互思考报告

基于产品核心承诺：秒级成卡、离线可用、精准表达。纯黑极简、无 emoji、禁技术术语、操作必反馈。

---

## 1. 主流程心智模型

**链路设计：3 步收敛为 2 步**

```
触发 → 表达式卡生成 → 全屏大字展示 → 完成
    ↘  （合并）  ↗
```

### 必须保留的步骤：
1. **触发**：用户明确的操作输入（语音/相机/文字）
2. **全屏大字**：表达式卡最终呈现形式
3. **完成**：表达式卡被对方理解

### 可以省略的步骤：
✅ **「成卡预览」省略**：直接进入全屏大字展示。理由：
- 出境用户注意力集中，额外的预览环节增加认知负荷
- 2 秒的生成时间不够长，预览变成「等待」的冗余
- 表达式卡本身已经是「成品」，全屏即是「最终交付」

### 设计决策（P0）：
- 卡片生成2秒超时，弹出骨架屏「翻译中…」，1秒刷新为「稍等，正在思考」
- 生成成功：直接平滑切入全屏大字，动画使用「卡片放大」的动效

## 2. 语音交互设计

**按住说话 vs 松开成卡 决策规则：**

| 使用场景 | 交互方式 | 逻辑 |
|----------|----------|------|
| **主动表达**（我方） | **按住说话** | 用户需要「中途可中止」的控制权：怀疑表达不准、想改词、怕误触敏感词 |
| **被动聆听**（对方回话） | **长按播放** | 用户需要「随时停止」的控制权：语言太快、想记笔记、需要翻页 |

### 设计决策（P0）：
- **表达卡生成**：语音输入 3 秒内停止按压，自动触发成卡；5 秒内可持续输入
- **播放对方回话**：长按播放按钮，松开即停止；播放期间亮起播放按钮作反馈
- **两种模式区分**：表达模式使用「麦克风+方框」图标，播放模式使用「耳机+波浪」图标

## 3. 紧急场景优先级

**「快」和「不误触」的平衡方案：**

### 触发机制：
- **双击护栏区域**：护栏位于屏幕左下角，双击激活「紧急模式」
- **护栏动画**：从屏幕底部弹出 3 个紧急卡片，背景色 #FF0000

### 卡片设计：
```
[保护] 我被抓了
[求助] 需要警察
[医疗] 我需要医院
[安全] 联系领事馆
[求爱] 我需要亲人
```

### 防误触设计：
- 卡片默认全屏不可滑动，只能「靠近底部」触发
- 执行操作前 3 秒「倒计时闪烁」，用户有机会取消
- 取消方式：**向上滑」或**「立即点击屏幕空白处」**

### 设计决策（P0）：
- 紧急卡片点击 500ms 延迟触发，视觉上「先亮红底区」再执行
- 每个卡片都携带「最近3次使用」标签，快速定位常用紧急表达

## 4. 空态与首次体验

**全新用户第一次打开 App：**

### 网络状态：
1. **有网络** → 展示「欢迎旅行」的滑块介绍 → 3 秒倒计时自动进入「触发」页
2. **无网络** → 展示「离线模式」的卡片 → 提示「首次使用需下载离线包」

### 无定位：
- 让用户手动选择「国家/地区」
- 搜索框「输入国名」或「选省份」
- 右上角「从地图选择」的备选方案

### 未下载离线包：
1. 显示「需要 12MB 离线数据包」的弹窗
2. 2 种选择：**「立即下载」**（WiFi 推荐） / **「稍后离线使用」**
3. 稍后离线：展示「文本输入」模式，语音/照片功能灰显

### 设计决策（P0）：
- 首次体验 3 步走：**「选择语言 → 了解功能 → 开始输入」**
- 离线模式下，默认使用「文字输入」+「已收藏的表达卡」+「最近浏览的物品」组合

## 5. 产品级交互矛盾或缺口

### 矛盾1：精准表达 vs 表达速度
- **矛盾**：用户希望「快速成卡」但又怕「表达式不够精准」
- **缺口**：没有「快速纠错」机制
- **解决**：
  - 全屏大字展示时，左下角添加「⚙️ 纠错」小按钮
  - 点击后弹出「替换词」的建议列表：「我想表达的是…」
  - **设计决策（P1）**：纠错弹窗右上角「接受更改」按钮，5 秒内有效

### 矛盾2：免费体验 vs 功能完整
- **矛盾**：免费用户可能会被「深度功能锁」吸引
- **缺口**：功能解锁提示过于突兀
- **解决**：
  - 将「深度场景」转化为「挑战」——「挑战 3 次成功表达」解锁下一关
  - 解锁成功后，弹出「恭喜，解锁『司机专属表达』」的庆祝动画

### 矛盾3：一致性 vs 场景适配
- **矛盾**：不同场景（机场/餐厅/医院）需要不同语言风格
- **缺口**：没有「情境模式」的切换入口
- **解决**：
  - 在「触发」页添加「情境」小标签栏：默认「通用」/「餐饮」/「购物」/「医疗」/「交通」
  - 选中情境后，表达卡底部显示「情境标签」+「该情境常用表达」
  - **设计决策（P2）**：情境标签灰度化，需要 3 次点击后自动弹出「情境快捷方式」浮层

### 矛盾4：完整性 vs 极简
- **矛盾**：用户需要「完整表达」但界面要求「极简」
- **缺口**：表达式卡信息量不足时，用户会担心表达不够清晰
- **解决**：
  - 在「表达式卡」底部添加「📋 详细版」的隐藏按钮
  - 点击后，从下方弹出「细节层」：
    - 本句中文释义
    - 常用近义词
    - 例句短语
  - 该层高度占满屏幕，滑动退出「细节层」即可返回表达式卡
  - **设计决策（P2）**：「详细版」按钮在无网络时灰显，提示「需要联网查看」

## 总结：核心设计决策优先级

| 决策 | 优先级 | 交付指标 |
|------|--------|----------|
| 主流程 3 步收敛为 2 步 | P0 | 表达式卡生成秒级完成，用户无需等待 |
| 语音按住 vs 松开机制 | P0 | 表达/播放模式按钮识别准确率 > 95% |
| 紧急场景 5 秒倒计时防误触 | P0 | 紧急模式误触率 < 1%，操作时间 < 8 秒 |
| 首次体验 3 步引导 | P0 | 首次触发者完成首卡率 > 85% |
| 纠错机制 5 秒免费纠错 | P1 | 纠错成功转化率 > 60% |
| 情境模式情境标签 | P2 | 餐饮类表达准确率提高 25% |
