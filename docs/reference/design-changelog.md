## SCN-01 — 06 屏 emoji 替换为国家码徽章
- **改动**: 06 国家选择屏 8 个国家卡片国旗由 emoji(🇹🇭🇯🇵🇰🇷🇻🇳🇸🇬🇲🇾🇮🇩🇱🇦)替换为两字母国家码文本(TH/JP/KR/VN/SG/MY/ID/LA),mono 字体 11px;头像 🧳 换"途"字。
- **原因**: 红线 1(无 emoji)。
- **状态**: ✅ 已实施

## SCN-02 — 06 屏技术文案修正
- **改动**: Profile `旅行者 · zh-CN` → `旅行者 · 简体中文`;GPS 徽标 → `定位`。
- **原因**: 红线 2(界面禁技术术语/代码)。
- **状态**: ✅ 已实施

## SCN-03 — 10 屏版本号改日期
- **改动**: Summary `场景包 v3.2` → `数据版本`;各国行 `v3.2`/`v3.1`/`v3.0` → `上次更新日期`(07-20/07-18/07-15…)。
- **原因**: 版本号对用户无意义且属技术心智;cmd 建议改为日期。
- **状态**: ✅ 已实施

## SCN-04 — 07/08 拨号防误触标注
- **改动**: 07 安全卡 3 个拨号块(191/1669/1155)+ 08 安全详情 3 个电话块,各加"长按拨打"9px 提示文字。
- **原因**: 紧急号码误触成本极高,需直给+防误触(红线 6 / cmd P0 建议)。
- **状态**: ✅ 已实施

## SCN-05 — InputBar placeholder 简化
- **改动**: `说出需求 / 打字 / 拍照...` → `输入你想说的话…`(组件定义,3 个实例同步)。
- **原因**: 原文案与触发区重复、无优先级。
- **状态**: ✅ 已实施

## SCN-06 — ExprCard 加"换一句"入口
- **改动**: 表达卡组件 Actions 区新增 `换一句` 按钮(rotate-ccw 图标 + 文字)。
- **原因**: cmd 建议表达不当时可重新生成,满足操作必反馈。
- **状态**: ✅ 已实施

## SCN-07 — 06 屏选中态强化
- **改动**: 泰国(当前选中)卡片加 2px 深色描边,强化选中语义。
- **原因**: cmd 建议选中卡片明确描边/勾选,避免选中逻辑未定义。
- **状态**: ✅ 已实施(勾选图标待补)

## SCN-08 — 01 屏 InputBar 移除 MicBtn
- **改动**: 01 IDLE 屏输入栏实例 MicBtn `enabled:false`;语音触发归中央 HoldMic。
- **原因**: 中央大 HoldMic 已定义"语音=按住说话"心智,底部 mic 冗余;InputBar 默认 MicBtn 在 02 屏已被 VoiceToggle 取代。
