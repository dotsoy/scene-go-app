# SceneGo 按钮流程闭环审计(工具/信息屏)

> 审计对象:`docs/reference/DESIGN-v2.1.pen`(Pencil 画布,13 屏)
> 审计范围:06 国家选择 / 07 安全卡 / 08 安全详情 / 09 位置切换提示 / 10 离线包状态,逐按钮检查「动作 → 反馈 → 结果 → 可返回/继续」闭环。
> 闭环判定:已闭环(动作+反馈+结果齐全)/ 半闭环(有动作无反馈)/ 未闭环(动作无反馈 + 无失败路径)。
> 优先级:**P0 = 必须补,P1 = 应该补,P2 = 可选**。

---

## 06 国家选择

### ① GPS 行(map-pin + "GPS 定位成功 · 泰国 曼谷")
- **触发动作**:设计未定义(仅展示成功态,疑似可点)。
- **下一状态**:无。
- **异常路径**:无 —— 未授权/定位中/失败三态全部缺失。
- **是否闭环**:**未闭环**。定位失败时用户无重试入口。
- **补全建议**(P1):赋予"点击重试定位";补定位中(spinner 旋转)、失败(黄字"定位失败,请手动选择")、未授权("前往设置")三态,颜色随语义变(green→yellow/red)。

### ② 国家卡片 ×8(泰国默认蓝底,其余灰底)
- **触发动作**:选中该国。
- **下一状态**:无 —— 无对勾/描边选中标记,泰国蓝底语义含糊(是"已选中"还是"推荐"?),切换选中时旧卡无回退态。
- **异常路径**:离线包未覆盖国家的选择无提示。
- **是否闭环**:**未闭环**。选中后无视觉确认。
- **补全建议**(P0):选中态 = 2px accent-blue 描边 + 右下角勾(check);点击其他卡片时旧卡回退 bg-card-light;未下载国家加"未下载"灰角标,点击提示"需联网下载后使用";列表与"26 国"对齐(当前仅 8 国,红线 5 数据不一致)。

### ③ Profile 行(🧳 旅行者 · zh-CN / 普通话 → 泰语)
- **触发动作**:无定义。
- **下一状态**:无。
- **异常路径**:无。
- **是否闭环**:**未闭环**。可点击性无意义。
- **补全建议**(P2):明确为"语言对设置"入口(点击进语言选择),并联动所选国家(选日本 → "普通话 → 日语");或声明为纯展示、去掉点击暗示。另:zh-CN 是技术文案,改"简体中文"。

### ④ 确认按钮"确认并生成安全卡"
- **触发动作**:异步生成安全卡 → 跳转 07。
- **下一状态**:无按压态、无 loading,画布上是直接跳转。
- **异常路径**:生成失败(无网络/服务不可用)无任何 UI。
- **是否闭环**:**未闭环**。异步动作无反馈,双击会重复提交。
- **补全建议**(P0):按压态(scale 0.98 + 亮度降低)→ loading("生成中…"+ spinner,按钮禁用防重复)→ 成功跳 07 / 失败按钮下红字"生成失败,请重试"。

## 07 安全卡

### ⑤ 关闭按钮 ✕
- **触发动作**:返回上一页。
- **下一状态**:系统返回,无异常。
- **异常路径**:无。
- **是否闭环**:**已闭环**(简单关闭类)。
- **补全建议**:无需。

### ⑥ "朗读求助句"
- **触发动作**:播放泰语求助语音。
- **下一状态**:无播放中态(图标不换、无波形/呼吸动画);播放中再点能否停止未定义。
- **异常路径**:无(离线语音缺失/音频焦点被占无提示)。
- **是否闭环**:**半闭环**。有动作无反馈。
- **补全建议**(P1):三态 —— 待播(volume-2 灰)/播放中(图标变绿 + 呼吸动画)/停止;播放失败 toast"语音暂不可用"。

### ⑦ "安全信息"按钮
- **触发动作**:进入 08(设计中为跳转,但 08 是抽屉,转场语义未定义)。
- **下一状态**:08 屏存在,但无转场动效定义;08 无关闭按钮,收起方式未定义(上滑被红线 3 禁止)。
- **异常路径**:无。
- **是否闭环**:**半闭环**。能进不能明确退。
- **补全建议**(P0):点按 0.25s 滑出抽屉 + mask 渐显;收起 = 点 mask / 抽屉顶部关闭按钮,不用上滑手势。

### ⑧ 拨号块 ×3(191/1669/1155,长按拨打)
- **触发动作**:长按 0.6s → 系统拨号(设计决策,但画布未落地)。
- **下一状态**:无长按进度环、无震动确认、无"正在拨打…"态。
- **异常路径**:无 —— 无 SIM、无拨号能力、拨打失败均无 UI。
- **是否闭环**:**未闭环**。防误触与反馈全部缺失,紧急场景最关键处。
- **补全建议**(P0):长按 0.6s + 进度环(描边渐满)+ 松手取消 + 满时震动拨号;失败态按钮变红"无法拨号,请手动拨打 191" + 数字可复制;拨号时自动停止朗读。

## 09 位置切换提示

### ⑭ "保持"按钮
- **触发动作**:关闭弹窗、维持当前国家。
- **下一状态**:无 —— 是否持久化记忆(24h 不再弹)未定义;无结果反馈。
- **异常路径**:无。
- **是否闭环**:**半闭环**。有动作无确认。
- **补全建议**(P1):关闭 + 持久化 + 首页位置行旁 2s toast"已保持 泰国 · 曼谷";位置行 chevron 提供常驻主动切换入口。

### ⑮ "切换"按钮
- **触发动作**:异步切换国家 + 语言 + 安全卡。
- **下一状态**:无 loading;无切换前预览(用户盲签);无成功 toast。
- **异常路径**:目标国离线包未下载(切换后离线能力丢失,未预警);下载失败无回滚。
- **是否闭环**:**未闭环**。异步动作三件套全缺。
- **补全建议**(P0):切换前预览卡(语言对 + 紧急号码变化)→ loading("切换中…"禁用)→ 成功 toast / 目标国未下载时二次确认"需联网使用,仍要切换?";失败回滚原国家 + 红字。

## 10 离线包状态

### ⑯ "检查更新"按钮
- **触发动作**:检查离线包更新。
- **下一状态**:无 loading;底部 hint"已是最新"是写死文案,不与按钮结果联动。
- **异常路径**:断网时无提示。
- **是否闭环**:**未闭环**。动作无结果反馈。
- **补全建议**(P1):loading("检查中…")→ 无更新 toast"已是最新" / 有更新按钮变主色"更新 3 国"一键全更 / 断网红字"网络不可用,请联网后重试"。产品层已建议删掉此按钮改后台静默更新,若采纳则整体移除。

- **下一状态**:无。
- **异常路径**:无。
- **是否闭环**:**半闭环**。展示本身完整,但无任何管理能力。
- **补全建议**(P1):行点击展开该国详情(紧急号码预览 + 占用空间);补"更新中/可更新/失败"三态动作(更新中 spinner 禁用、可更新黄点 + 更新按钮、失败灰 + 重试);列表补全 26 行与 Summary"26/26"对齐(当前仅 13 行,红线 5 数据不一致)。

## 闭环状态汇总

| 状态 | 元素 |
| --- | --- |
| **已闭环** | ⑤ 关闭按钮 |
| **半闭环**(有动作无反馈) | ⑥⑩ 播放类、⑦ 抽屉进出、⑫ 静态提示、⑭ 保持、⑰ 状态行 |
| **未闭环**(动作无反馈 + 无失败路径) | ①②③④ 06 全屏、⑧⑨⑪ 拨号类、⑬ 防诈骗、⑮ 切换、⑯ 检查更新 |

| 优先级 | 补全项 |

| **P0** | ② 国家卡片选中态与 26 国对齐;④ 确认按钮异步反馈;⑦ 抽屉收起方式;⑧⑨⑪ 拨号三件套(长按进度环 + 震动 + 拨打中/失败态);⑮ 切换预览与失败回滚 |
| **P1** | ① GPS 四态;⑥⑩ 播放三态;⑬ 防诈骗行动出口;⑭ 保持持久化;⑯ 检查更新结果反馈;⑰ 行状态三态与 26 行对齐 |
