# SceneGo 安全入口交互规范 · SafetyDrawer 分层

> 适用范围: SafetyFAB(56px 红色圆 + shield + 「安全」,已实例化 01/02/05/11/12/13 右下角)点按后的安全交互体系。
> 设计依据: product-cmd.md 安全信息三级分层(L0 常驻层 / L1 详情层 / L2 主动层)+ 长按防误触红线。
> 关联画布: 08 安全详情(底部抽屉 Sheet,紧急电话 · 长按拨打 + 3 拨号块 + 求助句 + 使馆 + 本地提示)。

---

## 1. L0 快速层 / L1 完整详情:分层定义

**结论: FAB 点按后先弹 L0 快速层(不是直接进 08)。** 紧急时用户的心智是「我要打 191」,不是「浏览详情」;L0 把「2 秒可达直呼号码」作为第一响应,L1 详情留给「需要完整信息」的场景。

### L0 快速层(2 秒可达: 直呼紧急号码)

| 内容 | 规格 |
| --- | --- |
| 3 个紧急号码块(按求助意图重排) | 191 遇到危险 / 1669 身体不适 / 1155 旅游纠纷;号码大字 + 意图主文案 + 「长按拨打」提示 |
| 当前国确认行 | 「泰国 · 曼谷」弱提示,防打错国家号码(跨国误触成本极高) |
| 进 L1 入口 | 「完整安全信息」文字链 → 展开为 08 抽屉 |
| 关闭 | 遮罩点击 / 下滑 / 顶栏 ✕(三出口,见第 2 节) |

- L0 固定为**底部半高抽屉**(非全屏):单手拇指可及号码块,急用时不需抬头找内容。
- 无求助句/使馆/提示:那些是「之后要做什么」,不在第一响应面;避免与紧急拨号竞争注意力(L0 只干一件事:拨号)。
- 意图排序 + 长按拨打沿用 08 现有交互(见第 3 节,07/08 已落地,直接复用)。

### L1 完整详情(= 现有 08 抽屉,内容不变)

| 内容 | 规格 |
| --- | --- |
| 紧急电话 · 长按拨打 | 3 拨号块(191/1669/1155,意图重排) |
| 求助句 | 当地语言求助句 + 朗读 |
| 中国使领馆 | 使馆名 + 电话(长按拨打) |
| 本地提示 | 电压 / 饮水 / 小费 + 防诈骗警示 |
| 事件路径(建议后续补) | 被偷 → 报警 → 补证件 → 联系使馆(product-cmd L1 建议,当前画布未含) |

- L1 = 完整安全信息,内容体量大,承载「阅读」而非「行动」,故为全高抽屉可滚动。
- L0 → L1 是**同一容器内展开**,不是二次模态:FAB → L0(半高)→ 上滑/点「完整安全信息」→ L1(全高)。层级连续,不叠模态。

### 层级关系

```
SafetyFAB(常驻入口)
  └─ 点按 ──▶ L0 快速层(半高抽屉, 紧急号码直呼) ── 点「完整安全信息」 ──▶ L1 完整详情(全高抽屉, 08)
                │                                                            │
                └─ 关闭: 遮罩 / 下滑 / ✕ ────────────────────────────────────┘
```

## 2. 打开 / 关闭交互规范

### 打开

| 触发 | 行为 |
| --- | --- |
| FAB 点按 | 上滑弹 L0 快速层(带 0.6s 进度环防误触 + 震动确认?**否**——FAB 是「打开抽屉」不是「拨号」,误触成本低,点按即开,不用长按。防误触只施加在**拨号动作**上) |

- **明确**: FAB 用**点按**,紧急号码用**长按 0.6s + 进度环 + 震动**。防误触资源只花在不可逆动作(拨号),不花在可逆动作(开抽屉)。

### 关闭(三出口,全部保留)

| 出口 | 行为 | 画布现状 |
| --- | --- | --- |
| 遮罩点击 | 点 L0/L1 遮罩关闭并收起 | L0 需补;08 现无遮罩点击规范(需标注) |
| 下滑关闭 | 从 Grabber 下滑收起(L0/L1 通用) | Grabber 已存在(36x4);下滑语义需明确绑定 |
| ✕ 关闭按钮 | 顶栏右上 ✕(L1 已有位置规范;L0 需补) | 08 Sheet 现无 ✕ 按钮(见第 3 节缺口) |

- **主出口建议**: L0 用「下滑 + 遮罩」(手势自然);L1 全高时下滑被系统手势占用风险高,补 ✕ 作为确定出口(与 SCN-12c「补上滑被禁后的收起方式」一致)。

### 组件策略

- **L0 = 新建轻量组件**(半高 Sheet 变体,含 3 号码块 + 当前国行 + 「完整安全信息」入口 + 关闭三件套),不复用 08 全高 Sheet——两者高度、内容、滚动性不同,硬复用会引入 08 的滚动/内容耦合。
- **L1 = 复用现有 08 Sheet** 组件(内容已达标),L0 通过「完整安全信息」链接到 08。
- 建议把 08 的 Sheet 容器抽为 **SafetySheet 可复用组件**(Grabber + SheetHeader + ✕ 关闭),L0/L1 共用外壳、内容各异——一处改关闭逻辑,两层同享。

## 4. FAB 常驻 / 不常驻屏边界

### 常驻屏(01/02/05/11/12/13)——已实例化

| 屏 | 角色 | 为何常驻 |
| --- | --- | --- |
| 01 IDLE 触发 | 主入口,用户在待机 | 紧急入口应在「无事可做」时可见 |
| 02 表达卡 | 成卡后展示给对方 | 卡展示中突发情况(对方情绪/环境),2 秒可达 |
| 05 图片解读 | 拍摄/识别结果 | 识别场景可能触发安全联想 |
| 11 对话(触发+活动流) | TabBar 主页面 | 全局常驻的安全底座 |
| 12 笔记(收藏) | TabBar 页面 | 同上 |
| 13 更多(设置聚合) | TabBar 页面 | 同上 |

→ **原则 A: 常驻 = 「可浏览/可待机」页面**。用户在页面停留、有空间放 FAB,紧急入口随时可见。

### 不常驻屏(03/04/07/08)

| 屏 | 角色 | 为何不常驻 |
| --- | --- | --- |
| 03 全屏大字展示 | 沉浸式展示给对方看 | 沉浸态,遮挡 = 打断;且对方可能正看屏幕 |
| 04 内联相机 | 取景 | 取景时 FAB 会误触拍照/遮取景框 |
| 07 安全卡 | 本身就是安全内容 | 安全页面内再放安全入口 = 冗余 |
| 08 安全详情 | 安全 L1 详情 | 同上,且 08 是 L1 本身 |

→ **原则 B: 不常驻 = 「沉浸/任务/安全页」页面**。沉浸态(03/04)防打断、防误触;安全页(07/08)内容即入口,重复放置无意义。

### 边界判据(一句话)

**「这个页面用户是否可能在做别的事(浏览/待机)且需要紧急入口?」** —— 是 → 常驻;否(沉浸/拍摄/正在看安全内容)→ 不常驻。
- 例外提示: 03 全屏展示若停留 >30s,可考虑「屏幕边缘 1px 细线 + 长按唤出」的隐式入口(可选增强,P2),当前规范不做。

## 5. 关键结论

1. **FAB 点按 → L0 快速层(半高,紧急号码直呼)→ 「完整安全信息」→ L1(08 全高详情)**,不是直接弹 08。L0 是「拨号面」,L1 是「阅读面」,2 秒可达靠 L0 的半高 + 意图重排 + 长按拨打实现。
2. **FAB 点按即开(不长按)**,防误触只施加在拨号动作(长按 0.6s + 进度环 + 震动);关闭三出口(遮罩/下滑/✕)全保留,L0 新建轻量组件、L1 复用 08,建议抽 SafetySheet 共用外壳。
3. **画布现状**: 08 抽屉、3 拨号块、长按拨打提示、FAB 组件均已达标;**核心缺口是 L0 快速层整体缺失 + 08 关闭出口(✕/遮罩)缺失**,FAB 点按动效与当前国行等为次要补充。
