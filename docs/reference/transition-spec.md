## 总则 — 三条导航原则

| # | 原则 | 规则 | 覆盖范围 |
|---|------|------|---------|
| P1 | **Tab 内切换用滑动** | 同 Tab 页面之间(对话↔笔记↔更多)永远水平滑动 + 惯性;不做 push/模态/抽屉 | 11↔12↔13 |
| P2 | **跨层级用模态/抽屉** | 需要中断当前任务、或保留下层上下文时使用。深下钻用 push推入,全量中断用 modal,面板叠层用 drawer(sheet) | 01→06、01→09、04→05、07→08、全局 FAB→08 |

## 一、三类转场的语义定义

### 1. Push 推入(PushTransition)

**语义**: 层级下钻——用户主动进入一个更详细的信息层,预期会返回。提供视觉"深度感"(从右滑入)。

**适用条件**:
- 用户主动点击列表项/卡片进入详情页
- 存在明确的前后关系(A→B,B 是 A 的子内容)
- 必须支持右滑返回(iOS 惯例)

**动画**:
- Enter: `translateX(390→0)` 右进,时长 300ms, easing `ease-out`
- Exit: `translateX(0→-390)` 左退,时长 300ms, easing `ease-in`
- iOS 标准导航栏压入动效(react-navigation `cardStyleInterpolator`)

**Reduce Motion**: 瞬切(fade-only, 150ms opacity 0→1),无位移。

### 2. Modal 模态(ModalsheetTransition)

**语义**: 全屏中断——需要用户聚焦完成单一任务,不完成不能继续下层操作。关闭后返回原位置原状态。

**适用条件**:
- 需要决策的任务(选择国家、切换目的地并确认预览)
- 表单输入(目的地搜索)
- 首次引导

**动画**:
- Enter: `scale(0.95→1) translateY(20→0)`, overlay fade-in, 时长 250ms, easing `ease-out`
- Exit: `scale(1→0.95) translateY(0→20)`, overlay fade-out, 时长 200ms, easing `ease-in`
- Mask 背景半透明黑(`rgba(0,0,0,0.6)`)

**手势关闭**: 点按 mask 外区域 / 右上角 ✕ CloseBtn / 系统返回手势。
**Reduce Motion**: 瞬切(fade-only, 150ms),无缩放/位移。

### 3. Drawer / Sheet 抽屉(SheetTransition)

**语义**: 面板叠层——不丢失上层上下文,快速查看/操作后可无感关闭。适合 L1 详情层(L0 应使用模态)。

**适用条件**:
- 安全详情(电话/使馆/求助句组)
- 设置页(可考虑侧拉,但当前统一底部 sheet)
- "接下来做什么"事件路径

**动画**:
- Enter: `translateY(100%→60%)`(部分展开到约 60vh),时长 300ms, easing `ease-out`
- Exit: `translateY(60%→100%)` 下滑闭合,时长 250ms, easing `ease-in`
- 顶部拖拽柄(handle),支持下拉关闭
- ⚠️ 禁止上滑触发成卡(iOS 冲突红线)

**手势关闭**: 下拉至阈值(< 1/3 visible)、右上 ✕ CloseBtn、点按 mask。
**Reduce Motion**: 瞬切,无位移。

## 四、逐项动画规格表

| 转场 | Enter 动画 | Enter 时长 | Exit 动画 | Exit 时长 | Reduce Motion |
|------|-----------|-----------|----------|----------|---------------|
| Push 推入(右进左退) | translateX(390→0) | 300ms | translateX(0→-390) | 300ms | fade 150ms |
| Modal 自下升起(scale) | scale(0.95→1) + translateY(20→0) + overlay fade | 250ms | scale(1→0.95) + translateY(0→20) + overlay fade | 200ms | fade 150ms |
| Card morph(卡片放大) | 从卡片锚点坐标 expand 至全屏 | 250ms | 从全屏 shrink 至卡片锚点 | 200ms | fade 150ms |
| Sheet 底部滑出 | translateY(100%→60vh) | 300ms | translateY(60vh→100%) | 250ms | fade 150ms |
| Tab 切换横滑 | translateX(width×index→nextIndex) | 200ms | reverse | 200ms | snap(禁用过渡) |
| In-place refresh(换一句) | opacity 0→1 + rotate-ccw icon spin 360° | 200ms | N/A(原地替换) | N/A | instant(opacity 不变) |
| Banner/Toast 滑入 | translateY(-100%→0) | 200ms | translateY(-100%→0)(向上收起) | 150ms | fade 150ms |
| Modal dismiss(确认选择) | scale(1→0.95) + overlay fade-out | 200ms | N/A | N/A | fade 150ms |

**共享参数**:
- Easing: 除 tab 切换用 `spring(mass:1, stiffness:200, damping:20)` 外,全部使用 `ease-out`(enter)/`ease-in`(exit)
- Overlay: 模态/drawer 的 mask 为 `rgba(0,0,0,0.6)`
- Content behind overlay: 不 blur(保持极简),仅降低 opacity 至 0.7

## 五、手势约定总览

| 手势 | 作用域 | 行为 | 备注 |
|------|-------|------|------|
| **右滑返回** | 所有 Push 页面 | 从左侧边缘右滑 → pop stack | 强制要求,符合 iOS 惯例 |
| **下拉关闭** | 所有 Drawer/Sheet | 从上方向下拉 > 1/3 visible → dismiss | 08 安全详情、SafetyDrawer |
| **上滑禁止** | 全局 | **禁用** | iOS 系统手势冲突,红线 |
| **长按成卡** | 01 HoldMic | 按下 → 录音波形反馈 → 松开 → 生成中 → 全屏大字 | 核心交互,0.6s 防误触阈值 |
| **长按拨打** | 07/08 拨号块 | 按下 0.6s → 进度环 + 震动 → 拨号 | 红线防误触 |
| **点 mask 关闭** | 所有 Modal/Sheet | 点击遮罩层 → dismiss | 与点击子元素区分(防止穿透) |
| **横滑翻页** | Tab 容器(11/12/13) | 左右横滑 → 切换 Tab | snap scroll + 弹性惯性 |
| **拖拽柄拖动** | Drawer top handle | 上下拖动调整高度,松手吸附 | 仅 Drawer,不用于 Modal |
| **双击护栏** | 左下角(安全入口) | 双击 → 打开 SafetyDrawer | 与 FAB 互补的双触发之一(待实现) |

## 七、与安全相关的转场专项

由于安全是低频高严重度场景,转场设计有特殊约束:

### 安全转场原则

| # | 原则 | 描述 |
|---|------|------|
| S1 | **确定性** | 无论从哪个 Tab/页面出发,SafetyFAB 永远在同一位置、打开同样的 Drawer。不因上下文改变行为 |
| S2 | **不破坏当前流** | SafetyDrawer 以 overlay 形式存在,不 pop/push 导航栈;关闭后精确回到触发前的位置和状态 |
| S3 | **一键可达** | SafetyFAB 在右下角拇指舒适区,z-index:999;从任意状态最多一次点击可达 |
| S4 | **L0 快, L1 慢** | L0 意图按钮点按即触发(无需二次确认,靠长按 0.6s 防误触);L1 号码/使馆是信息浏览,可自由滚动 |
| S5 | **离线不可断** | 安全转场(打开 Drawer、展示 L0/L1)完全不依赖网络。只有在展示使馆地址/在线预警时才标记"需联网"灰显 |

### SafetyDrawer 层级结构

## 八、文档维护规则

本规范为活文档,遵循以下维护规则:

1. **每批 SCN 实施后更新**: 如果新增或修改了任何转场类型(即使只是加了个 BackBtn),须在此规范第 2 节"转场映射表"中更新对应的"画布现状"列。
2. **缺口自动升级**: 某个缺口连续两个迭代未被解决,自动升一级优先级并在 changelog "下一步待定"中标注。
3. **Reduce Motion 验证**: 每次转场变更必须在"Reduced Motion"模式下测试确认降级效果正常。
4. **手势兼容性检查**: 新增页面必须确认没有引入上滑手势冲突(红线)。
5. **handoff §5 同步更新**: 本规范生效后,将 `design-session-handoff.md` §5"结构性缺口"中"转场语义规范未建立"一行划掉(`~~...~~ → ✅ SCN-XX 已建`).
