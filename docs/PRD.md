# Product Requirements Document (PRD) — SceneGo

> 更新：2026-08-03 —— 依据产品决策（**用户主动触发生成表达卡，不自动触发**），以当前代码实现为准。

## 1. 产品概述

SceneGo 面向**全球出境用户**：**用户主动触发**（拍照 / 语音 / 文字），App 识别当前场景并生成**符合该场景的当地语言表达卡**，让用户能立即把需求/情境有效地传达给当地人（司机、店员、警察、海关等）。

数据基础：10 类场景词库 + 26 国安全信息（版本化场景包，离线可用，可远程下发）。核心承诺：**秒级成卡、离线可用、精准表达**。

## 2. 核心功能规格

### 2.1 主动触发机制（用户主动，App 不自动触发）

- **CAM 双击拍照**：对准菜单 / 路牌 / 售票机拍照 → 提取信息 → 直接生成表达卡；卡面提供「AI 解读」多轮追问入口
- **MIC 双击语音**：说出需求（如"我要打车""我对花生过敏"）→ 生成当地语言表达卡；iOS 原生听写（Android 明确降级提示，引导拍照/文字）
- **Tap & Talk 文字表达**：一句话描述需求 → 生成当地语言表达卡
- **位置上下文（非触发）**：一次性前台定位（5 分钟缓存），用于国家匹配、安全卡与语言推断；不监听、不自动弹卡，权限拒绝不影响分析

### 2.2 表达卡系统

- **大字闪示卡**：当地语言大字 + 拉丁转写发音 + 本地惯例提示 + 一键 TTS 朗读，直接递给当地人看
- **双源生成**：离线词库匹配（本地快、免网络、成本零）与云端 VLM 动态生成（精准、可追问）互为兜底
- **安全卡**：按国家提供紧急电话（警察/急救/火警/旅游警察）、中国使领馆电话、求助句、骗局提示，一键拨打

### 2.3 本地工具

- 快速笔记（凭证/密码/退款号，一键复制、全屏大字）
- 会话历史（本地保存快照会话，可恢复追问）
- 表达卡 / 快照分享导出
