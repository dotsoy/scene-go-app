## 一、产品概述

面向**全球出境用户**：**用户主动触发**（拍照 / 语音 / 文字），App 识别当前场景并生成**符合该场景的当地语言表达卡**，让用户能立即把需求/情境有效地传达给当地人（司机、店员、警察、海关等）。

数据基础：10 类场景词库 + 26 国安全信息（版本化场景包，离线可用）。核心承诺：**秒级成卡、离线可用、精准表达**。

## 二、正在做的

|---|---|---|
| 机场场景推荐 | 🔄 设计中 | 到机场自动推荐：打车 / 末班车 / 买流量卡 |
| 打车 · 听懂司机回应 | 🔄 设计中 | 司机说话实时翻译成中文，听不懂还能「换句话重说」 |
| 点菜 · 菜单解读 | 🔄 设计中 | 拍菜单 → 招牌菜 / 过敏预警 / 辣度，点哪个菜出哪张卡 |
| 买药 · 分步引导 | 🔄 设计中 | 三步：说症状 → 说过敏 → 问用法用量 |
| 紧急电话 · 二次确认 | 🔄 设计中 | 拨 191/1669 前先弹确认，防止误触误拨 |

**为什么做这些（现在的短板）**：卡片只能递给当地人看，对方一开口就卡壳；拍菜单只出一张菜卡，还是不知道点什么；到了机场/深夜 App 一片空白没人引导；买药退税这种多步骤的事一张卡说不清。

## 三、功能规划（未开始）

| 能力 | 说明 |
|---|---|
| 订阅权益（IAP） | 付费解锁全部功能：可购买、可恢复、可取消；未订阅只能用基础能力 |
