# PLAN.md · 规划（未开始的能力）

> 完成状态以 [`ROADMAP.md`](ROADMAP.md) 为准（本文件不维护状态）。

## 一、产品功能规划

| 能力 | 说明 |
|---|---|
| 订阅权益（IAP） | 付费解锁全部功能：可购买、可恢复、可取消；未订阅只能用基础能力 |
| Android 语音 | Android 手机也能语音生成表达卡（现在只有 iPhone 可以） |
| 城市内容 SOP | 曼谷 → 东京 → 首尔/新加坡；每城一套（打车/餐饮/退税/地铁/SOS + 本地规则），每周更新 |
| 分享 / 邀请 | 邀请码/链接（表达卡截图分享已上线） |
| 落地页 + ASO | 官网（兼隐私政策宿主）、关键词、商店截图 |
| 免费 / 付费分层 | 每日免费 N 次 AI 识别 → 订阅解锁无限 |
| eSIM 场景返佣 | 机场卡内嵌流量卡推荐 |
| 用户自定义场景卡（UGC） | 开放卡片模板 |
| 离线场景包下载 + 20+ 语言 | 离线可用是核心价值主张 |

## 二、暂不规划（一句话）

场景包远程下发、AI 服务端代理（客户端部分均已实现）、商店上架、崩溃监控、账号体系、数据统计这些后端和运营的活暂时不做，需要时再说。
