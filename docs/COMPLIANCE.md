# SceneGo 合规文档（隐私政策 / 用户协议 / 数据清单）

> 状态：v1，更新 2026-08-03
> App 内展示文本见 `src/data/compliance.ts`（本文件为审核用权威版本，二者保持一致）。
> 注意：当前版本为纯客户端 + 云端 AI 识别（无账号/后端）。订阅（IAP）上线后必须同步更新本文件（订阅条款、自动续费说明）。

## 一、隐私政策

### 1. 我们收集哪些信息
- **相机照片**：用户拍摄的场景照片仅在设备上压缩处理；为完成场景识别与翻译，照片内容会发送至第三方 AI 服务商（OpenRouter）处理。
- **语音内容**：语音转写使用 iOS 系统级语音识别（SFSpeechRecognizer），识别在设备端完成，语音本身不上传。
- **位置信息**：用于匹配所在国家以生成安全卡片与场景建议；仅在用户授权后于设备端使用，不持续上传或存储。
- **笔记与会话记录**：快速笔记、翻译会话历史保存在设备本地（AsyncStorage），不自动上传。

### 2. 信息的存储与安全
- 本地数据仅存储于用户设备，删除 App 即全部清除。
- API 密钥等敏感信息使用系统安全存储（iOS Keychain）。
- 发送至云端 AI 的图片与文本通过 HTTPS 加密传输。

### 3. 第三方服务
- **OpenRouter**：场景识别与翻译 AI 服务商，处理用户提交的图片与文本，受其隐私政策约束。
- 不出售、不出租用户任何个人信息。

### 4. 用户权利
- 可随时删除设备上的全部本地数据（卸载 App 或清除应用数据）。
- 可在隐私设置中撤销相机/麦克风/位置权限，不影响使用其他功能。

## 二、用户协议

1. **服务说明**：SceneGo 提供基于 AI 的场景识别、翻译与出行表达辅助，仅供出行辅助参考，不构成法律、医疗或紧急救援建议。
2. **紧急情况**：涉及人身安全的紧急情况请优先拨打当地紧急电话（见 App 安全卡），不依赖 AI 输出作为唯一求助渠道。
3. **AI 内容免责**：AI 生成的翻译、解读与提示可能存在错误；重要信息（价格、过敏原、法律条款、退税规则）以官方信息为准。
4. **用户行为**：不得将服务用于违法用途（欺诈、骚扰、侵犯他人权益等）。
5. **订阅与收费**：若提供付费订阅，遵循应用商店订阅规则（自动续费、取消方式、退款政策以商店规定为准），用户可随时取消自动续费。
6. **责任限制**：在法律允许范围内，对因使用本服务产生的间接损失（误机、经济损失等）不承担责任。

## 三、数据清单

| 数据 | 用途 | 存储位置 | 是否上传 |
| --- | --- | --- | --- |
| 相机照片 | 场景识别与翻译 | 设备临时文件 | 是（发往 OpenRouter，处理后不保留） |
| 语音 | 实时转写 | 不存储 | 否（设备端识别） |
| 位置 | 国家匹配/安全卡 | 设备端 | 否 |
| 笔记/会话 | 个人记录 | 设备 AsyncStorage | 否 |
| API 密钥 | 调用识别服务 | iOS Keychain | 否（直接用于请求） |
| 崩溃信息 | 稳定性改进 | 商店崩溃报告（无第三方） | 是（不含照片/语音） |

**保留期限**：本地数据保留至用户主动删除或卸载应用；云端 AI 服务按第三方政策保留处理内容（通常不用于训练）。

**数据共享**：仅在必要范围内与 OpenRouter（AI 服务）共享；不与广告商、数据经纪商共享任何数据。

## 上架审核配套（App Store / Play Console）

- 年龄分级：建议 4+（无用户生成内容、无成人内容）；如启用社区功能需复审。
- 隐私清单（App Privacy）：需在 App Store Connect 声明「照片/图片」与「崩溃数据」收集项，对应本数据清单。
- 订阅产品：IAP 元数据需与用户协议第 5 条一致。
