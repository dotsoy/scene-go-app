把手机变成与世界的沟通遥控器

SceneGo 是极致极简的出境游沟通工具。它不需要你学会任何国家的语言——只需要按住说话、打字或拍照， 把卡片递给对方。但我们无法独自完成这一切。

PRODUCT PHILOSOPHY

产品形态：极致极简

01

唯一入口

不分类、不导航。一个屏承载按住说话、打字、拍照全部输入，没有底部 Tab，没有预设场景标签。

02

Action Card 流

每一轮沟通是一张独立卡片：外语在上、母语在下。点卡全屏递给对方，多轮对话像聊天一样自然。

03

图像理解

拍菜单、标识或实物，原地解读——原文、含义与实用表达，一并呈现。

WHY WE BUILD TOGETHER

为什么需要共建

01

产品刻意保持极简

没有底部导航、没有分类标签、没有完成按钮。任务发生在现实世界，不在手机里。

02

价值在内容，不在功能

极简的壳之下，真正的价值是各国场景词库、翻译质量与沟通模板——这是内容工程。

03

一个人做不完全世界

195 个国家的语言、场景与沟通习惯，需要真正到过那些地方的人来共同完善。

WAYS TO CONTRIBUTE

五种方式参与共建

CONTENT

场景内容

整理你熟悉的场景（打车、点餐、问路、就医），补充当地真实说法与沟通习惯。

 TRANSLATION

翻译校对

校对我方生成的外语表达，确保语法自然、口吻得体、贴近当地实际。

 DESIGN

设计与体验

让卡片更清晰、更克制，让每一步交互都更快到达现实世界。

 TESTING

真机测试

在真实旅途中使用并反馈：哪些话当地人不明白，哪些场景缺失。

 CODE

代码与引擎

打磨语音识别、图像理解与离线词库，让它在无网环境也可靠。
HOW TO START

三步加入共建

01

提出 Issue

告诉我们你熟悉的场景或发现的问题，例如「在日本便利店怎么买烟」。

 02

认领任务

在项目看板中选择你感兴趣的内容条目，标注开始工作。

 03

提交 PR

补充词库、校对翻译或改进代码，通过评审后合入。
